# 矩阵分析课程导航

> [!abstract] 主教材与学习范围
> 主教材：Carl D. Meyer《Matrix Analysis and Applied Linear Algebra》初版（2000）。本课共12章：第1—8章保留原书及63个节号；第9—12章为按主题自编的课程章节，不是 Meyer 的原书章号。
> 空间、基、像与核、矩阵表示及换基见[[数学/研究生课程/01-矩阵分析/第04章-向量空间|第4章]]；直和与一般投影见[[数学/研究生课程/01-矩阵分析/第05章-范数内积与正交性#5.9 互补子空间（Complementary Subspaces）|5.9 互补子空间]]。算法实现、优化建模等跨课知识从相应章节链接。

## 前置课程

**直接前置**：[[数学/本科基础/02-线性代数/00-课程导航|线性代数]]。

**同组顺序**：01 矩阵分析 → 02 数值分析 → 03 最优化 → 04 李群与李代数 → 05 随机过程 → 06 数理统计 → 07 测度论 → 08 高等概率论

本课是本科线性代数的深化：从向量空间、范数与内积、谱理论和 Perron–Frobenius 理论，进入矩阵微积分、广义逆、Kronecker 积及 λ-矩阵与标准形。

## 使用约定

- **编号**：第1—8章及其节号按 Meyer 初版；第9—12章及其节号为课程自编，来源另注。文件名补零只为排序；不混用2023年第二版目录。
- **标题层级**：一级标题为章，二级编号标题为节，三级标题为节内学习分点。相关知识直接列在对应章、节；其他课程的知识只链接，不复制第二份正文。
- **中文是笔记译名**：原书节标题保留英文便于对照，不宣称与某个中文版逐字一致。
- **来源真实**：不批量填写未经核对的PDF页码、题号或定理位置；实体页与印刷页不套用统一偏移。
- **状态反映实际内容**：第4章为“核心知识已整理”，第5章为“部分已整理”；第9章核心知识已整理，第10—12章目前为框架。笔记整理进度与学习掌握程度分开记录。
- **填写方式**：定义、条件、证明思路、例题放在对应学习标题下；章末保留习题、计算实验与复盘入口。

## 阅读顺序建议

1. **基础工具：第1—3章。** 已掌握消元、阶梯形、矩阵运算和 LU 的部分可以快读，重点检查等价变换与数值敏感性。

3. **谱理论与函数：第6—7章。** 第6章补足行列式工具；第7章串联对角化、Jordan 结构、矩阵函数和动力系统。
4. **进阶应用：第8章。** 在谱与矩阵幂的基础上理解非负系统和 Markov 链。
5. **矩阵运算与结构：第9—12章。** 第9章接矩阵函数，第10章接最小二乘与SVD，第11章接矩阵运算及谱，第12章与第7章的相似分类对照。可以按先修关系穿插阅读；课程目录不等于学校考试范围。
