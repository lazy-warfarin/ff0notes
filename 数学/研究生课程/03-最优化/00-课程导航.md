# 最优化课程导航

> [!abstract] 双教材与学习范围
> 入门和概念铺垫参考 **Chong–Żak《An Introduction to Optimization》第2版（2001）**，算法深度和数值实现参考 **Nocedal–Wright《Numerical Optimization》第2版（2006）**。
> 两书合并为第0—22章，共23章，另列2篇选读专题；每章一篇笔记，列出节、小节、学习目标及复盘入口。当前只建立框架，不表示正文、例题或习题已经完成。
> 已核对本机 PDF 的版本和完整目录；下面的细分学习标题是按主题整合的提纲，不声称已经逐节核读两书全部正文。

## 前置课程

**直接前置**：[[数学/本科基础/01-微积分/00-课程导航|微积分]]（多元部分）、[[数学/本科基础/02-线性代数/00-课程导航|线性代数]]。

**同组顺序**：01 矩阵分析 → 02 数值分析 → 03 最优化 → 04 李群与李代数 → 05 随机过程 → 06 数理统计 → 07 测度论 → 08 高等概率论

本课以梯度、Jacobian、Hessian、Taylor 展开、二次型和正定性为基础。[[数学/研究生课程/01-矩阵分析/00-课程导航|矩阵分析]]中的空间、范数、谱、条件数、QR/SVD，以及[[数学/研究生课程/02-数值分析/00-课程导航|数值分析]]中的误差、线性系统和最小二乘可以按需回查；不要求先把两门课全部学完。

课程范围覆盖连续最优化的建模、最优性条件、无约束方法、线性与二次规划、一般非线性约束算法。非线性最小二乘、Gauss–Newton 和 LM 是连接点云配准、标定、BA、位姿图优化的重要工具；这些研究应用只列衔接入口，不把它们冒充原书项目。

## 使用约定

- **综合编号，不冒充原书目录**：本课程第0—22章、节号和小节号均为自编。章文件补零用于排序；C 与 NW 原书编号只出现在“对照”或来源说明中。
- **教材简称**：C = Chong–Żak 第2版；NW = Nocedal–Wright 第2版。不是此前推荐时介绍的 C 第4/5版，不混用新版目录。
- **标题层级**：一级标题为章；二级编号标题为节；三级编号标题为学习小节。选读专题使用 S1、S2 前缀，避免与主线章号混淆。
- **两书去重整合**：重复主题只维护一份主笔记，利用每节“对照”回到不同教材。数学准备可以快读，凸性工具适当前置，最小二乘单独成章。
- **注明整理边界**：导数检查、停止准则比较及研究应用等跨章归纳明确标为“整理分点”；不将其称为原书的正式小节。
- **保留原书中的选读内容**：神经网络和遗传算法来自 C 原书，只是移到选读区，不意味着原书没有。C 第2版第14章是 Genetic Algorithms，不是新版的 Global Search Algorithms。
- **不凭空扩充教材范围**：不把新版 SGD、整数规划、多目标优化或其他教材的近端法、ADMM、流形优化混入本次两书目录。非光滑精确罚保留在其本来位置，不等于建立完整非光滑优化课程。
- **统一符号**：约束理论填写时默认等式 h(x) = 0、不等式 g(x) ≤ 0；对照 NW 的其他符号约定时显式转换。
- **来源与状态真实**：不批量预填未经核对的页码、题号、定理编号或完成标记。PDF 实体页与印刷页不套用统一偏移；所有新章目前均为“框架”。
- **填写方式**：定义、假设、推导、例题逐步放进对应小节；章末保留习题、计算实验、易错点和待解决问题，暂不指定编程语言。

## 阅读顺序建议

1. **第一轮入门：第0—5章。** 数学准备按需查阅，先掌握模型、最优性、凸性、线搜索、梯度和 Newton；第9章的导数计算可伴随实现提前读。
2. **补足无约束主线：第6—8章、第11章。** 重点把共轭方向、曲率近似、信赖域与最小二乘串起来；第10、12—13章按问题需要再深入，不要求先完成它们才能开始约束理论。
3. **系统学习约束问题：第14—18章。** 先用线性规划理解几何和对偶，再进入一般 KKT、凸对偶与 QP；已有线性规划基础时可先读第16章。
4. **进阶算法：第19—22章。** 比较投影、罚函数、增广 Lagrange、SQP 与内点法；细致的全局收敛证明、历史算法及大型实现可以分轮阅读。
5. **研究应用衔接。** 面向点云配准和标定，可在无约束基础后重点读第9、11章，并回查数值分析的最小二乘笔记；涉及姿态更新再接李群课程。两篇选读专题不作为这条路线的强制先修。

以上是学习组织建议，不等同学校考试范围，也不表示两本教材必须一学期全部精读。
