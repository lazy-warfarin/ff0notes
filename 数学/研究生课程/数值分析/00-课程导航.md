# 数值分析课程导航

主要教材：Timothy Sauer《Numerical Analysis》英文第3版。笔记分为第0—13章和附录A/B，每章一篇。

第0章将误差分析排在前面，使用连续的节、小节编号；第3章已整理插值基础及相关讨论。内容已整理不表示已经掌握，目标与实验清单按实际学习进度填写。

## 使用约定

- **编号**：章号保留第0—13章，文件名补零只为排序。第0章按学习顺序自编节号，原书节号另行注明；其他章节仍沿用原书编号。
- **标题层级**：一级标题为章，二级标题采用0.1、0.2等节号，三级标题采用0.1.1、0.1.2等小节号。
- **中文标题是笔记译名**：保留重要英文术语，方便对照英文教材；不宣称与某个中译本逐字一致，也不预填未经核对的页码或题号。
- **应用项目集中到章末**：第1—13章保留 Reality Check 项目入口；第0章和附录不虚构项目。
- **保留填写空间**：各章末设有例题与习题、计算实验、易错点与待解决问题。实验语言在实际填写时再选择，MATLAB 附录仅用于对照教材。
