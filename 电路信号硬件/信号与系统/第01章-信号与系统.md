## 1.0 引言

*Introduction*

**信号**是承载信息的函数或序列，例如电压随时间变化的波形、传感器的样值序列、由像素坐标索引的图像。**系统**把一个输入信号映射为输出信号，通常记作 $y=\mathcal S\{x\}$。比如测得的温度是信号；把温度序列平滑后输出的是系统。分析时先定清输入、输出和自变量，再讨论这些量怎么变。

第一章先建立两组工具：信号这一侧要会**表示、变换、分解**，系统这一侧要会**建模和判别性质**。到第2章，就能把「分解成冲激」和「线性＋时不变」合起来，推导[[电路信号硬件/信号与系统/第02章-线性时不变系统#2.1 离散时间LTI系统：卷积和|卷积和]]。

## 1.1 连续时间信号与离散时间信号

*Continuous-Time and Discrete-Time Signals*

连续时间记作 $x(t)$，$t\in\mathbb R$；离散时间记作 $x[n]$，$n\in\mathbb Z$。圆括号与方括号在这门课里区分自变量的类型。连续时间信号可以在某点跳变；离散时间说的是只有整数索引处有样值。

### 1.1.1 信号的例子与数学表示

*Examples and Mathematical Representation*

#### 从物理量到函数

- 连续时间：话筒电压 $v(t)$ 或电容电压 $v_C(t)$，每个时刻都有对应值，可以用表达式或波形图表示。
- 离散时间：按间隔 $T_s$ 记录的电压 $x[n]=v(nT_s)$。画序列时用竖线标出各样值，$n=0$ 的位置也要标清。按天记录的温度、按像素索引的图像也可天然离散。
- 一维信号只有一个独立变量；图像 $I[m,n]$ 有两个空间索引，仍适用「用自变量索引函数值」的思路。

#### 分类有几个独立的维度

| 看哪一方面 | 常见类别 | 判断依据 |
| --- | --- | --- |
| 自变量 | 连续时间、离散时间 | $t$ 取实数，或 $n$ 只取整数 |
| 幅值 | 连续取值、量化取值 | 采样只离散化时间；量化才把幅值放进有限或可数的等级 |
| 可预测性 | 确定性、随机 | 已定波形可用函数给出；噪声常用统计特性刻画 |
| 是否重复 | 周期、非周期 | 是否存在对全部时刻都成立的正移位 |
| 平方量的累积 | 能量信号、功率信号、两者皆非 | 分别检查总能量和长期平均功率 |
| 取值与持续范围 | 实值、复值；有限时长、无限时长 | $x$ 的值域与非零区间，可以分别判断 |

按本课程的分类，时间和幅值都连续取值的是**模拟信号**；时间和幅值都离散取值的是**数字信号**。ADC可拆成**采样 → 量化 → 编码**：刚采样出的 $x[n]$ 仍可能取任意实值；量化后只保留有限个幅值等级，再编码成数字记录。复信号常把两个实分量打包，声音、电压等实际测量量通常用实值表示。采样频率如何选见[[电路信号硬件/信号与系统/第07章-采样#7.1 以样本表示连续时间信号：采样定理|第7章采样定理]]。

教材：[[Signals and Systems - Oppenheim, Willsky, Nawab - 2nd ed (1998 reprint).pdf#page=27|Oppenheim §1.1.1 表示]] · [[电路信号硬件/信号与系统/教材/郑君里等-信号与系统（第3版·上册）.pdf#page=20|郑君里§1.2 信号分类]]。

### 1.1.2 信号能量与功率

*Signal Energy and Power*

先对有限窗口算平方量，再让窗口变长。以下用**时间向两边延伸**的平均定义；复信号必须取 $|x|^2=x\overline{x}$。例如 $x(t)$ 是加在 $1\,\Omega$ 电阻上的电压时，$|x(t)|^2$ 就是瞬时功率的数值；用于一般信号时，把它理解为平方量即可。

$$
\begin{aligned}
E_{\mathrm c}&=\int_{-\infty}^{\infty}|x(t)|^2\,dt,&
P_{\mathrm c}&=\lim_{T\to\infty}\frac{1}{2T}\int_{-T}^{T}|x(t)|^2\,dt,\\
E_{\mathrm d}&=\sum_{n=-\infty}^{\infty}|x[n]|^2,&
P_{\mathrm d}&=\lim_{N\to\infty}\frac{1}{2N+1}\sum_{n=-N}^{N}|x[n]|^2.
\end{aligned}
$$

- **能量信号**：$0<E<\infty$。窗口内的积分或求和被总能量所限制，分母趋于无穷，因此 $P=0$。
- **功率信号**：$0<P<\infty$，因而 $E=\infty$。周期信号若一周期的能量有限且非零，就属于这一类。求平均功率只需在任意**一个完整周期**内对平方量求平均。零信号 $E=P=0$，不落在上面两个严格分类内。
- **两者皆非**：例如 $x[n]=n$ 的总能量和平均功率都发散。$P=0$ 也不能单独推出有限能量，如 $x[n]=(1+n)^{-1/2}$（$n\ge0$，其余置零），平方和按调和级数发散，但平均值趋于0。

**例（自编）**：幅度为 $A$、宽度为 $D$ 的单个矩形脉冲有 $E=|A|^2D$、$P=0$。将同一脉冲以 $T_0>D$ 为周期重复，变成 $E=\infty$、$P=|A|^2D/T_0$（$A\ne0$）。对 $A\cos(\omega_0t+\phi)$（$\omega_0\ne0$），一周期内 $\cos^2$ 的均值是 $1/2$，所以 $P=|A|^2/2$。

教材：[[Signals and Systems - Oppenheim, Willsky, Nawab - 2nd ed (1998 reprint).pdf#page=31|Oppenheim §1.1.2 能量和功率定义]]。

## 1.2 自变量变换

*Transformations of the Independent Variable*

先分清改的是**横轴**还是**高度**：$x(at+b)$ 改变原信号取值的时刻，$Ax(t)+B$ 改变每个时刻的幅值。两者可以合在一个表达式里，画图时分别处理。

### 1.2.1 自变量变换举例

*Examples of Transformations of the Independent Variable*

#### 用原波形的特征点找新位置

| 变换 | 怎样读 |
| --- | --- |
| $x(t-t_0)$、$x[n-n_0]$ | $t_0,n_0>0$ 时右移（延时） |
| $x(-t)$、$x[-n]$ | 关于原点反褶 |
| $x(at)$ | $\lvert a\rvert>1$ 压缩，$0<\lvert a\rvert<1$ 拉伸；$a<0$ 再反褶 |
| $x(\alpha t+\beta)$ | 对原特征点 $s$ 解 $\alpha t+\beta=s$，新位置是 $(s-\beta)/\alpha$，其中 $\alpha\ne0$ |

**例（自编）**：原信号 $x(s)=s$（$0\le s<2$），其他时间为0。画 $y(t)=2x(1-2t)$。原来的 $s=0$ 对应 $t=1/2$；$s=2$ 对应 $t=-1/2$。再把 $x$ 的幅值乘2，得到

$$
y(t)=\begin{cases}
2-4t,&-1/2<t\le 1/2,\\
0,&\text{其他时刻}.
\end{cases}
$$

原波形向右上升，新波形在 $(-1/2,1/2]$ 内向右下降。分不清先平移还是先尺度变换时，直接解特征点位置最可靠。

#### 离散时间与其他常用运算

- $y[n]=x[2n]$ 只取原序列的偶数下标；$x[n/2]$ 在奇数 $n$ 处没有天然定义。若题目指2倍插零扩展，则对偶数 $n$ 取 $x[n/2]$，对奇数 $n$ 置零。
- 同一时刻可以对两个信号相加或相乘。如 $x(t)[u(t-a)-u(t-b)]$ 在 $a<b$ 时保留信号在门内的部分。信号逐点相乘与第2章的滑动卷积是两种操作。
- 连续时间用 $dx/dt$ 表示变化率，用 $\int_{t_0}^t x(\tau)\,d\tau$ 表示从 $t_0$ 起累积；离散时间可用一阶差分 $x[n]-x[n-1]$ 和累加作对应。若波形在某点跳变，求连续导数时还要加该点的冲激（见[[#1.4.2 连续时间单位阶跃函数和单位冲激函数|1.4.2]]）。

教材：[[Signals and Systems - Oppenheim, Willsky, Nawab - 2nd ed (1998 reprint).pdf#page=34|Oppenheim §1.2.1 自变量变换]] · [[电路信号硬件/信号与系统/教材/郑君里等-信号与系统（第3版·上册）.pdf#page=27|郑君里§1.3 移位、反褶、尺度与波形运算]]。

### 1.2.2 周期信号

*Periodic Signals*

连续时间若存在 $T>0$，使 $x(t+T)=x(t)$ 对所有 $t$ 成立，则 $x(t)$ 周期；最小的正周期称为**基本周期** $T_0$。离散时间同理，只是 $N$ 必须是正整数，要求 $x[n+N]=x[n]$ 对所有整数 $n$ 成立。连续时间常数每个 $T>0$ 都是周期，所以没有最小正周期；离散时间常数的最小正整数周期是1。

- $A\cos(\omega_0t+\phi)$（$A\ne0,\ \omega_0\ne0$）的基本周期是 $2\pi/|\omega_0|$。
- 对互不抵消的不同频率分量，如果所有分量能凑出同一个正周期，和信号就周期。两条非零连续正弦频率的比为有理数时才有公周期。例如 $\cos(2t)+\sin(3t)$ 的基本周期为 $2\pi$；$\cos t+\cos(\sqrt2t)$ 没有公周期。
- 离散周期序列的各个整数周期可用最小公倍数求一个共同周期；相加后若有抵消或实际对称性，还要检查更小周期。单个离散正弦的判据见[[#1.3.3 离散时间复指数的周期性|1.3.3]]。

周期定义要检查全时间轴。一个只持续若干个整周期、其余都为零的正弦脉冲整段仍是非周期信号。

教材：[[Signals and Systems - Oppenheim, Willsky, Nawab - 2nd ed (1998 reprint).pdf#page=37|Oppenheim §1.2.2 周期性]]。

### 1.2.3 偶信号与奇信号

*Even and Odd Signals*

偶信号满足 $x(-t)=x(t)$，奇信号满足 $x(-t)=-x(t)$；离散情形把 $t$ 换成 $n$。用原信号和反褶后的信号做半和、半差，任意定义在两侧的信号都可唯一分解：

$$
x(t)=x_{\mathrm e}(t)+x_{\mathrm o}(t),\quad
x_{\mathrm e}(t)=\frac{x(t)+x(-t)}2,\quad
x_{\mathrm o}(t)=\frac{x(t)-x(-t)}2.
$$

例如 $x(t)=t^2+2t+1$ 的偶部是 $t^2+1$，奇部是 $2t$。奇信号在原点有定义时必有 $x(0)=0$；复信号的奇偶性也是看 $t\mapsto -t$，不附带共轭。对于对称的一周期区间，偶信号与奇基函数的投影为零，因此可用奇偶性简化[[电路信号硬件/信号与系统/第03章-周期信号的傅里叶级数表示#3.3.2 连续时间周期信号傅里叶级数表示的确定|傅里叶级数系数]]的计算。

教材：[[Signals and Systems - Oppenheim, Willsky, Nawab - 2nd ed (1998 reprint).pdf#page=39|Oppenheim §1.2.3 奇偶分解]] · [[电路信号硬件/信号与系统/教材/郑君里等-信号与系统（第3版·上册）.pdf#page=41|郑君里§1.5 信号分解]]。

## 1.3 指数信号与正弦信号

*Exponential and Sinusoidal Signals*

指数模型用很少的参数就能表达增长、衰减或振荡。连续时间的参数写在指数里 $e^{st}$；离散时间常写成底数的整数幂 $a^n$。相同的振荡形式移到离散时间后，频率只在模 $2\pi$ 的意义下区分。

### 1.3.1 连续时间复指数信号与正弦信号

*Continuous-Time Complex Exponential and Sinusoidal Signals*

设 $C=|C|e^{j\phi}$，$s=\sigma+j\omega$。用欧拉公式分出幅度包络和相位：

$$
x(t)=Ce^{st}=|C|e^{\sigma t}e^{j(\omega t+\phi)},\qquad
\operatorname{Re}\{x(t)\}=|C|e^{\sigma t}\cos(\omega t+\phi).
$$

- 当 $t$ 增大时，$\sigma<0$ 的包络衰减，$\sigma>0$ 的包络增长，$\sigma=0$ 的包络不变。衰减形式 $e^{-t/\tau}$ 的时间常数 $\tau>0$，经过 $\tau$ 包络变为原来的 $1/e$。若建模为 $t=0$ 才接通，写成 $e^{-t/\tau}u(t)$。
- $e^{j\omega t}$（$\omega\ne0$）的基本周期是 $2\pi/|\omega|$，$\omega$ 的单位为rad/s，对应普通频率 $f=\omega/(2\pi)$（Hz）。$\omega$ 的正负决定复平面的转动方向。
- 实余弦可以看成一对共轭复指数的和：$A\cos(\omega t+\phi)=\frac{A}{2}e^{j\phi}e^{j\omega t}+\frac{A}{2}e^{-j\phi}e^{-j\omega t}$（$A$ 为实数）。这解释了以后一个实余弦为什么在正、负频率各占一项。

比如 $e^{-2t}\cos(6t+\pi/4)u(t)$ 的时间常数为 $1/2\,\mathrm s$，载波角频率为 $6\,\mathrm{rad/s}$，载波基本周期为 $\pi/3\,\mathrm s$；整条带衰减和接通信号则不周期。

**郑君里版的另外两类典型波形**：抽样函数 $\operatorname{Sa}(z)=\sin z/z$（$z=0$ 取极限1）是偶函数，非零零点是 $k\pi$；高斯钟形可写为 $Ae^{-\alpha t^2}$（$\alpha>0$）。$\operatorname{Sa}$ 的名字叫抽样函数，本身是连续时间函数；后面若遇到 $\operatorname{sinc}$，先核对它表示 $\sin z/z$ 还是 $\sin(\pi z)/(\pi z)$。

教材：[[Signals and Systems - Oppenheim, Willsky, Nawab - 2nd ed (1998 reprint).pdf#page=41|Oppenheim §1.3.1 连续复指数]] · [[电路信号硬件/信号与系统/教材/郑君里等-信号与系统（第3版·上册）.pdf#page=24|郑君里§1.2 典型信号示例]]。

### 1.3.2 离散时间复指数信号与正弦信号

*Discrete-Time Complex Exponential and Sinusoidal Signals*

设 $a=re^{j\Omega}$，$C=|C|e^{j\phi}$，对两边整数幂取 $r>0$。则

$$
x[n]=Ca^n=|C|r^ne^{j(\Omega n+\phi)},\qquad
\operatorname{Re}\{x[n]\}=|C|r^n\cos(\Omega n+\phi).
$$

随 $n$ 向正方向增加，$0<r<1$ 衰减，$r>1$ 增长，$r=1$ 为等幅振荡。底数为负实数时，$(-r)^n=(-1)^nr^n$，符号在相邻样值处交替。常见序列 $a^nu[n]$ 在负下标为零，和两边都定义的 $a^n$ 应分开看。

$\Omega$ 的单位是rad/sample。当 $x(t)=e^{j\omega t}$ 按 $T_s$ 采样，$x[n]=e^{j\omega T_s n}$，因此 $\Omega=\omega T_s$。由于 $n$ 是整数，$e^{j(\Omega+2\pi m)n}=e^{j\Omega n}$（整数 $m$）。例如 $e^{j(5\pi/4)n}=e^{-j(3\pi/4)n}$，这些是同一个序列。连续信号不同的角频率却可以在采样后得到同一组样值，这就是后面讨论混叠时要用的事实。

教材：[[Signals and Systems - Oppenheim, Willsky, Nawab - 2nd ed (1998 reprint).pdf#page=47|Oppenheim §1.3.2 离散复指数]]。

### 1.3.3 离散时间复指数的周期性

*Periodicity Properties of Discrete-Time Complex Exponentials*

非零等幅复指数 $x[n]=Ce^{j\Omega_0n}$ 周期的条件是

$$
x[n+N]=x[n]\ \Longleftrightarrow\ e^{j\Omega_0N}=1
\ \Longleftrightarrow\ \frac{\Omega_0}{2\pi}=\frac{k}{N},\qquad k\in\mathbb Z,\ N\in\mathbb Z_{>0}.
$$

所以 $\Omega_0/(2\pi)$ **必须是有理数**。约成既约分数 $p/q$（$q>0$）后，所有正整数周期都是 $q$ 的倍数，基本周期就是 $q$。例如 $\Omega_0=4\pi/5$ 时，比例是 $2/5$、基本周期为5；$\Omega_0=1\,\mathrm{rad/sample}$ 时比例是 $1/(2\pi)$，没有周期。对非退化的实正弦也可按此判别；如果给定的幅度和相位使序列恒为0或常数（如 $\sin(\pi n)$），直接按常数序列处理。

若取共同周期 $N$，谐波 $e^{j2\pi kn/N}$ 随 $k$ 增加 $N$ 就重复，因此只有 $N$ 种不同的谐波。这个结论会用于[[电路信号硬件/信号与系统/第03章-周期信号的傅里叶级数表示#3.6 离散时间周期信号的傅里叶级数表示|离散时间傅里叶级数]]。

教材：[[Signals and Systems - Oppenheim, Willsky, Nawab - 2nd ed (1998 reprint).pdf#page=51|Oppenheim §1.3.3 离散周期性]]。

## 1.4 单位冲激函数与单位阶跃函数

*The Unit Impulse and Unit Step Functions*

阶跃描述从某一时刻接通，冲激描述集中在某一时刻的激励。连续和离散的记号很像，读法不同：连续冲激用**面积（权重）**，离散冲激用**样值**。

### 1.4.1 离散时间单位冲激序列与单位阶跃序列

*The Discrete-Time Unit Impulse and Unit Step Sequences*

$$
\delta[n]=\begin{cases}1,&n=0,\\0,&n\ne0,\end{cases}
\qquad
u[n]=\begin{cases}1,&n\ge0,\\0,&n<0.\end{cases}
$$

阶跃的一阶差分只在跳变处非零，所以 $\delta[n]=u[n]-u[n-1]$，反过来 $u[n]=\sum_{k=-\infty}^{n}\delta[k]=\sum_{k=0}^{\infty}\delta[n-k]$。门序列 $u[n-a]-u[n-b]$（整数 $a<b$）在 $n=a,\dots,b-1$ 取1，末端 $b$ 不在门内。

乘冲激能筛出一个样值：$x[n]\delta[n-n_0]=x[n_0]\delta[n-n_0]$。把每个样值都写成移位冲激的权重，就有 $x[n]=\sum_k x[k]\delta[n-k]$。例如只有 $x[-1]=2$、$x[2]=-3$ 非零的序列可以写成 $2\delta[n+1]-3\delta[n-2]$。注意这里是以任意整数 $n$ 为观察点：右边只有 $k=n$ 的一项被留下。

教材：[[Signals and Systems - Oppenheim, Willsky, Nawab - 2nd ed (1998 reprint).pdf#page=56|Oppenheim §1.4.1 单位冲激和阶跃序列]]。

### 1.4.2 连续时间单位阶跃函数和单位冲激函数

*The Continuous-Time Unit Step and Unit Impulse Functions*

#### 用阶跃和斜坡写分段信号

$u(t)$ 在 $t<0$ 时为0、$t>0$ 时为1。$t=0$ 的单点约定可按题意确定，对普通积分没有影响。$u(t-a)-u(t-b)$（$a<b$）给出幅度1、从 $a$ 到 $b$ 的门；$r(t)=t u(t)$ 是单位斜坡（单位斜变），其导数是 $u(t)$。例如 $r(t)-r(t-D)$（$D>0$）在 $0<t<D$ 线性上升，在 $t>D$ 保持高度 $D$。符号函数在 $t\ne0$ 时可写成 $\operatorname{sgn}(t)=2u(t)-1$。

#### 连续冲激：单位面积、筛选与尺度变换

用宽度 $\varepsilon$、高度 $1/\varepsilon$ 的矩形逼近：令 $p_\varepsilon(t)=1/\varepsilon$（$|t|<\varepsilon/2$），其余为0。缩小宽度时面积始终为1；对在 $t_0$ 连续的 $g$，$\int g(t)p_\varepsilon(t-t_0)dt$ 是 $g$ 在短区间内的平均值，极限是 $g(t_0)$。连续冲激 $\delta(t)$ 按这种**对积分的作用**理解，不给它规定某个有限的点值。

$$
\int_{-\infty}^{\infty}g(t)\delta(t-t_0)\,dt=g(t_0),\qquad
g(t)\delta(t-t_0)=g(t_0)\delta(t-t_0).
$$

$\delta(-t)=\delta(t)$。若把冲激的自变量缩放，令 $s=at-b$；变元替换的积分因子为 $1/|a|$（负 $a$ 还会反转积分限）。因而

$$
\delta(at-b)=\frac1{|a|}\delta\!\left(t-\frac ba\right),\qquad a\ne0.
$$

例如 $\int (t^2+1)\delta(2t-4)\,dt=(2^2+1)/2=5/2$，积分范围为全实轴。离散冲激则只检查整数根：对 $\delta[an-b]$，令 $a,b$ 都是整数且 $a\ne0$；如果 $b/a$ 是整数，它等于 $\delta[n-b/a]$；否则恒为0，没有 $1/|a|$ 的面积因子。

#### 跳变、冲激与冲激偶

在广义函数意义下，$u'(t)=\delta(t)$；对 $t\ne0$，$\int_{-\infty}^t\delta(\tau)\,d\tau=u(t)$，跳变点的取值仍按所用约定。一段分段光滑波形的导数由**各段普通导数**再加上**各跳变处的冲激**组成；冲激的系数就是右极限减左极限。比如

$$
\frac{d}{dt}\left[e^{-t}u(t)\right]=-e^{-t}u(t)+\delta(t).
$$

$\delta'(t-t_0)$ 是冲激偶（冲激的导数）。对在 $t_0$ 光滑的测试函数，按分部积分的定义 $\int g(t)\delta'(t-t_0)\,dt=-g'(t_0)$，负号不能省。理想电容的 $i=C\,dv_C/dt$ 也说明了跳变模型的含义：若电容电压跳升 $\Delta V$，就需要权重为 $C\Delta V$ 的冲激电流。

教材：[[Signals and Systems - Oppenheim, Willsky, Nawab - 2nd ed (1998 reprint).pdf#page=58|Oppenheim §1.4.2 连续阶跃与冲激]] · [[电路信号硬件/信号与系统/教材/郑君里等-信号与系统（第3版·上册）.pdf#page=31|郑君里§1.4 斜坡、阶跃、冲激]] · [[电路信号硬件/信号与系统/教材/郑君里等-信号与系统（第3版·上册）.pdf#page=39|郑君里§1.4 冲激偶]]。

## 1.5 连续时间系统和离散时间系统

*Continuous-Time and Discrete-Time Systems*

系统描述的是**整条输入与整条输出的关系**。连续到连续用 $y(t)=\mathcal S\{x\}(t)$，离散到离散用 $y[n]=\mathcal S\{x\}[n]$。还可以有连续到离散的采样和离散到连续的重建。若输出由微分或差分方程隐式给出，要检查是否还需指定初始值或边界条件，才能确定唯一输出。若规则直接给成 $y(t)=x'(t)$，则在导数存在处可直接计算，无需另设初值。

### 1.5.1 简单系统举例

*Simple Examples of Systems*

| 系统 | 输入与输出关系 | 从模型读出的信息 |
| --- | --- | --- |
| 电阻 | 输入电流 $i(t)$，输出电压 $v(t)=Ri(t)$ | 只依赖同一时刻的输入 |
| RC低通 | 输入 $x(t)$，取电容电压为输出 $y(t)$：$RC\,dy/dt+y=x$ | 输出要结合初始电容电压；时间常数是 $RC$ |
| 三点平滑 | $y[n]=(x[n]+x[n-1]+x[n-2])/3$ | 只用当前及过去两点，三项加权求和 |
| 离散累加 | $y[n]=y[n-1]+x[n]$ | 需给初值；若初始静止且输入从 $n=0$ 开始，则 $y[n]=\sum_{k=0}^{n}x[k]$（$n\ge0$） |

RC式来自 $x=Ri+y$ 和 $i=C\,dy/dt$。实际建模先写规律，再选输入、输出和初始状态；同一电路选不同输出，得到的系统可以不同。郑君里版有更完整的二阶RLC建模，见[[#郑1.6 系统模型及其分类|郑1.6]]。

教材：[[Signals and Systems - Oppenheim, Willsky, Nawab - 2nd ed (1998 reprint).pdf#page=65|Oppenheim §1.5.1 系统示例]] · [[电路信号硬件/信号与系统/教材/郑君里等-信号与系统（第3版·上册）.pdf#page=46|郑君里§1.6 系统模型]]。

### 1.5.2 系统的互联

*Interconnections of Systems*

- **串联（级联）**：前一级的输出送进后一级，$v=\mathcal S_1\{x\}$，$y=\mathcal S_2\{v\}$。一般不能交换。两倍增益后平方得到 $4x^2$，平方后加两倍增益则是 $2x^2$。
- **并联**：同一输入送进各支路，再按接法合成输出。如并联相加为 $y=\mathcal S_1\{x\}+\mathcal S_2\{x\}$。
- **反馈**：输出经过反馈支路送回输入端。以负反馈为例，$e=x-\mathcal B\{y\}$，$y=\mathcal F\{e\}$；需要联立看整个回路，单看某个支路不能判断闭环是否稳定。

看方框图时可先给中间信号命名，再从加法器和各块写出等式。郑君里版用**加法、比例和积分**模块实现连续方程；离散递推里常用**相加、增益和单位延迟**。反馈分析见[[电路信号硬件/信号与系统/第11章-线性反馈系统|第11章]]。

教材：[[Signals and Systems - Oppenheim, Willsky, Nawab - 2nd ed (1998 reprint).pdf#page=67|Oppenheim §1.5.2 系统互联]] · [[电路信号硬件/信号与系统/教材/郑君里等-信号与系统（第3版·上册）.pdf#page=48|郑君里§1.6 基本运算方框图]]。

## 1.6 基本系统性质

*Basic System Properties*

六项性质分别问：输出要用哪些输入值、能否从输出还原输入、有没有用到未来、幅值会不会失去界限、输入换一个开工时间结果怎么变、多个输入能不能分开算。**证明成立要覆盖所有允许的输入；否定只需一个反例。** 有初始状态的系统先说明初始化规则；以下默认规则相同。

### 1.6.1 有记忆系统与无记忆系统

*Systems with and without Memory*

**无记忆**：每个时刻只需要同一时刻的输入值。连续时间可写作 $y(t)=g_t(x(t))$；$g_t$ 可以随 $t$ 变化。若当下输入相同，输出仍可能因别处的输入不同而改变，系统就有记忆。

- $y[n]=x[n]^2$、$y[n]=(-1)^n x[n]$ 都无记忆；后者虽然每一拍的增益不同，但没调用别的样值。
- $y[n]=x[n-1]$ 有记忆；$y[n]=x[n+1]$ 也有记忆，只是用了下一拍的输入。
- 电容有记忆：给定初始电压后，$v_C(t)=v_C(t_0)+C^{-1}\int_{t_0}^{t}i(\tau)\,d\tau$；当下电流相同，过去积累的电荷不同，电压仍可不同。

教材：[[Signals and Systems - Oppenheim, Willsky, Nawab - 2nd ed (1998 reprint).pdf#page=70|Oppenheim §1.6.1 无记忆与有记忆]]。

### 1.6.2 可逆性与逆系统

*Invertibility and Inverse Systems*

**可逆**：在指定的输入集合里，不同输入必须产生不同输出，即 $\mathcal S\{x_1\}=\mathcal S\{x_2\}$ 能推出 $x_1=x_2$。若成立，就可对系统实际能产生的每个输出定义逆映射，使 $\mathcal S^{-1}\{\mathcal S\{x\}\}=x$。

- $y[n]=2x[n]$ 的逆是 $x[n]=y[n]/2$。对全体实值序列，$y[n]=x[n]^2$ 把 $x$ 与 $-x$ 映成同一个输出；若限制每个样点都非负，则可以逐点取非负平方根。判断前要看输入范围。
- 对双边序列，$y[n]=x[n-1]$ 的逆是 $x[n]=y[n+1]$。原系统因果，逆系统要用未来一个样点，适合离线还原。
- 全体双边序列中，差分 $y[n]=x[n]-x[n-1]$ 会丢掉常数；若已知 $x[n]=0$（$n<0$），就可用 $x[n]=\sum_{k=0}^{n}y[k]$（$n\ge0$）还原。边界条件补回了丢失的信息。

教材：[[Signals and Systems - Oppenheim, Willsky, Nawab - 2nd ed (1998 reprint).pdf#page=71|Oppenheim §1.6.2 可逆与逆系统]]。

### 1.6.3 因果性

*Causality*

**因果**：如果两条输入在 $t_0$ 及以前完全相同，那么它们在 $t_0$ 处的输出也必须相同（采用相同的初始化规则）。离散情形把 $t_0$ 换为 $n_0$。无记忆系统必然因果；因果系统可以利用过去，所以可以有记忆。

- $y[n]=x[n]+x[n-2]$ 是因果；$y[n]=x[n]+x[n+1]$ 就不是。后者可找两条输入：都在 $n\le0$ 为零，但在 $n=1$ 处一个是0、另一个是1，因此 $y[0]$ 不同。
- $y(t)=x(2t)$ 在 $t>0$ 取到未来，所以在全时间轴上不是因果系统。$y(t)=\cos(t)x(t)$ 只用当下的值，因果性不受显式的 $t$ 系数影响。

离线处理可用已保存的未来样点，例如居中平滑；实时处理若必须等下一点，通常要引入等待或延迟。**因果系统**是输入输出的性质，**因果信号**是 $t<0$（或 $n<0$）为零的信号。

教材：[[Signals and Systems - Oppenheim, Willsky, Nawab - 2nd ed (1998 reprint).pdf#page=72|Oppenheim §1.6.3 因果性]] · [[电路信号硬件/信号与系统/教材/郑君里等-信号与系统（第3版·上册）.pdf#page=52|郑君里§1.7 因果性]]。

### 1.6.4 稳定性

*Stability*

这里使用 **BIBO稳定**（Bounded-Input Bounded-Output，有界输入有界输出）：每一条整段幅度有界的输入都应产生整段幅度有界的输出。证明时可先设 $|x[n]|\le M<\infty$，再找不依赖 $n$ 的有限输出上界。

- $y[n]=(x[n]+x[n-1]+x[n-2])/3$ 满足 $|y[n]|\le M$，因此稳定。
- $y[n]=n\,x[n]$ 可用有界常数输入 $x[n]=1$ 反驳，输出为 $n$，没有全局上界。
- 对从过去累加的系统 $y[n]=\sum_{k=-\infty}^{n}x[k]$，取 $x[n]=u[n]$，输出从 $n=0$ 起就是 $n+1$，故不BIBO稳定。这条累加规则是因果的，在求和存在的信号类上也是线性时不变的。

先用常数、阶跃等简单输入找反例；找不到反例时仍要给对任意有界输入成立的估计。LTI系统可用冲激响应判稳定，见[[电路信号硬件/信号与系统/第02章-线性时不变系统#2.3.7 线性时不变系统的稳定性|第2章§2.3.7]]。

教材：[[Signals and Systems - Oppenheim, Willsky, Nawab - 2nd ed (1998 reprint).pdf#page=74|Oppenheim §1.6.4 BIBO稳定性]]。

### 1.6.5 时不变性

*Time Invariance*

**时不变**：先把输入延时再过系统，与先过系统再把输出延时，结果相同。记延时算子为 $D_{t_0}$，则对所有输入和位移有 $\mathcal S D_{t_0}x=D_{t_0}\mathcal S x$。连续写 $t_0$，离散位移 $n_0$ 为整数。

1. 写原输出 $y_1(t)=\mathcal S\{x\}(t)$，把它改为 $y_1(t-t_0)$。
2. 另设新输入 $x_2(t)=x(t-t_0)$，仍用原来的系统规则算 $y_2(t)$。
3. 比较两个结果。第二步只换输入，系统自身的函数和系数原样保留。

**例（自编）**：$y(t)=x(2t)$ 对延时输入给 $y_2(t)=x(2t-t_0)$，而原输出延时给 $y_1(t-t_0)=x(2t-2t_0)$，一般不相同，故时变。离散例 $y[n]=(-1)^n x[n]$ 对一拍延时给 $(-1)^n x[n-1]$，先算输出再延时是 $(-1)^{n-1}x[n-1]$，也可判时变。

反过来，系统式含 $t$ 或 $n$ 不能直接判时变。例如 $y(t)=x(t-2)$ 用的是**固定时差**，两种顺序都给 $x(t-t_0-2)$，所以时不变。

教材：[[Signals and Systems - Oppenheim, Willsky, Nawab - 2nd ed (1998 reprint).pdf#page=76|Oppenheim §1.6.5 时不变性]]。

### 1.6.6 线性

*Linearity*

**线性**要求对任意允许的 $x_1,x_2$ 和标量 $a,b$，

$$
\mathcal S\{a x_1+b x_2\}=a\mathcal S\{x_1\}+b\mathcal S\{x_2\}.
$$

这包含**可加性**和**齐次性**。最省力的检查是先算零输入：若 $\mathcal S\{0\}\ne0$，立刻否定线性；即使 $\mathcal S\{0\}=0$，也还要继续检查叠加。

- $y[n]=x[n]-2x[n-1]$ 可直接代入验证线性；即便改成 $(-1)^n x[n]$，每个时刻对输入仍是线性的，只是系统时变。
- $y[n]=x[n]^2$ 有零输入零输出，但输入加倍会使输出变四倍，故不线性。
- $y[n]=2x[n]+1$ 的零输入输出为1，是仿射映射。类似地，固定非零初值的线性方程常给出「零状态响应＋固定的零输入响应」；零输入响应非零时，总映射是仿射的，扣除这个固定响应后的输入增量仍满足叠加。

教材：[[Signals and Systems - Oppenheim, Willsky, Nawab - 2nd ed (1998 reprint).pdf#page=79|Oppenheim §1.6.6 线性与叠加]] · [[Signals and Systems - Oppenheim, Willsky, Nawab - 2nd ed (1998 reprint).pdf#page=82|Oppenheim 增量线性]] · [[电路信号硬件/信号与系统/教材/郑君里等-信号与系统（第3版·上册）.pdf#page=51|郑君里§1.7 叠加性和均匀性]]。

## 1.7 小结

*Summary*

#### 六项性质放在一起验

以下把输入看成双边实值序列，稳定性用有界输入检验，可逆性不额外假定信号非负或已知边界。

| 系统 | 无记忆 | 可逆 | 因果 | BIBO稳定 | 时不变 | 线性 |
| --- | --- | --- | --- | --- | --- | --- |
| $y[n]=2x[n]$ | 是 | 是 | 是 | 是 | 是 | 是 |
| $y[n]=x[n-1]$ | 否 | 是 | 是 | 是 | 是 | 是 |
| $y[n]=x[n+1]$ | 否 | 是 | 否 | 是 | 是 | 是 |
| $y[n]=x[n]^2$ | 是 | 否 | 是 | 是 | 是 | 否 |
| $y[n]=(-1)^n x[n]$ | 是 | 是 | 是 | 是 | 否 | 是 |
| $y[n]=2x[n]+1$ | 是 | 是 | 是 | 是 | 是 | 否 |

做题时可以按这个顺序过一遍：先看输出用了哪个时刻的输入，再看是否丢信息、是否有统一的时间上界，最后分别做**移位试验**和**叠加试验**。例如「线性＋时不变」只说明是LTI；是否因果、是否BIBO稳定，仍要另外判。

下一章要用的两个事实：任意序列可以分解成移位冲激的加权和；LTI系统对移位冲激的响应是原冲激响应做同样的移位。把它们合起来就是[[电路信号硬件/信号与系统/第02章-线性时不变系统#2.1.2 离散时间单位冲激响应与LTI系统的卷积和表示|第2章的卷积推导]]。

### 郑1.5 信号的分解

对读：[[#1.2.3 偶信号与奇信号|1.2.3]]、[[电路信号硬件/信号与系统/第02章-线性时不变系统#2.1.1 用冲激表示离散时间信号|第2章 2.1.1]]、[[电路信号硬件/信号与系统/第03章-周期信号的傅里叶级数表示#3.3 连续时间周期信号的傅里叶级数表示|第3章 3.3]]。

同一个信号可以按不同目的分解：

- **直流和交流**：周期信号的直流值是 $x_{\mathrm{DC}}=T_0^{-1}\int_{t_0}^{t_0+T_0}x(t)\,dt$，交流部分 $x_{\mathrm{AC}}=x-x_{\mathrm{DC}}$ 一周期内均值为0。求非周期信号的长期平均前，要先检查它是否存在。
- **偶部和奇部**：分别用反褶的半和、半差，见[[#1.2.3 偶信号与奇信号|1.2.3]]。
- **脉冲或阶跃分量**：用窄矩形拼一段阶梯近似，第 $k$ 个矩形的高度取样值。也可以在每次改变高度时叠加一个移位阶跃：前一段高 $a$、后一段高 $b$，就在改变点加入权重 $b-a$ 的阶跃。窄脉冲极限引出[[电路信号硬件/信号与系统/第02章-线性时不变系统#2.2.1 用冲激表示连续时间信号|连续冲激分解]]。
- **实部和虚部**：$x=x_{\mathrm R}+j x_{\mathrm I}$，其中 $x_{\mathrm R}=(x+\overline{x})/2$、$x_{\mathrm I}=(x-\overline{x})/(2j)$。实虚分解通过共轭操作，奇偶分解通过时间反褶。
- **正交函数分量**：用内积求在各基函数上的投影；后续会把周期信号拆成不同谐波。见[[电路信号硬件/信号与系统/补01-信号矢量空间、相关与匹配滤波#郑6.3 信号的正交函数分解|补01 正交分解]]。

郑版在本节末还介绍**分形描述**：用不同尺度上的自相似性描述某些复杂波形。这里先了解这一思路；后续傅里叶推导用的是正交展开。

教材：[[电路信号硬件/信号与系统/教材/郑君里等-信号与系统（第3版·上册）.pdf#page=41|郑君里§1.5 分解方法]] · [[电路信号硬件/信号与系统/教材/郑君里等-信号与系统（第3版·上册）.pdf#page=45|郑君里 实虚、正交与分形]]。

### 郑1.6 系统模型及其分类

对读：[[#1.5 连续时间系统和离散时间系统|1.5]]。

#### 从物理关系写成系统模型

以理想串联RLC为例。输入电压 $e(t)$，电容电荷 $q(t)$，电流 $i=q'$。基尔霍夫电压定律给出

$$
L\frac{d^2q}{dt^2}+R\frac{dq}{dt}+\frac{q}{C}=e(t).
$$

取 $q$ 为输出，这是输入输出的微分方程。也可把电流与电荷分别作为状态，写成 $i'=(e-Ri-q/C)/L$、$q'=i$，用加法、比例和两个积分模块实现。两种写法描述同一个模型，求解都须给初始电流和初始电荷。

- 元件为常值线性理想元件，采用零状态输入输出映射，得到LTI系统。
- 若电容由外部事先规定为 $C(t)$，$q/C(t)$ 仍对 $q$ 线性，但模型一般时变。
- 若伏安关系本身非线性，例如 $v_R=R i^2$，模型会出现 $R(q')^2$；即使参数恒定，也不满足叠加。

这个简化模型忽略高频寄生效应。建模前要先问输入、输出和关注的工作范围是什么。

### 郑1.7 线性时不变系统

对读：[[#1.6.5 时不变性|1.6.5]]、[[#1.6.6 线性|1.6.6]]、[[电路信号硬件/信号与系统/第02章-线性时不变系统#2.0 引言|第2章 2.0]]。

郑版把**叠加性、齐次性、时不变性**作为后续LTI分析的基础。若 $\mathcal S\{x\}=y$，由线性与时不变性可以得到差商关系

$$
\mathcal S\!\left\{\frac{x(t+\Delta)-x(t)}{\Delta}\right\}
=\frac{y(t+\Delta)-y(t)}{\Delta}.
$$

在允许系统与极限交换时令 $\Delta\to0$，得到 $\mathcal S\{x'\}=y'$。同样，从 $-\infty$ 积起的积分可以看成移位信号的叠加；在积分收敛且允许交换时，先积分再过系统和反过来的结果相同。实时因果性仍需另外判断，例如提前一拍的系统是LTI，但用了未来样值。

教材：[[电路信号硬件/信号与系统/教材/郑君里等-信号与系统（第3版·上册）.pdf#page=51|郑君里§1.7 线性时不变系统]] · [[电路信号硬件/信号与系统/教材/郑君里等-信号与系统（第3版·上册）.pdf#page=52|郑君里 微分关系与因果性]]。

### 郑1.8 LTI系统分析方法、本书概貌

对读：[[#1.6 基本系统性质|1.6]]、[[电路信号硬件/信号与系统/第02章-线性时不变系统#2.0 引言|第2章 2.0]]。

同一个LTI系统可以从两条路分析。**时域**直接用微分／差分方程、冲激或阶跃响应叠加来求解。**变换域**把信号拆成频率或复频率分量，分别求响应后再合成；在适当条件下，卷积变为逐点相乘。两条路都用到了「分解 → 分别求响应 → 叠加」。先看[[电路信号硬件/信号与系统/第02章-线性时不变系统#2.1 离散时间LTI系统：卷积和|第2章时域卷积]]，再看[[电路信号硬件/信号与系统/第04章-连续时间傅里叶变换#4.4 卷积性质|第4章卷积定理]]。教材：[[电路信号硬件/信号与系统/教材/郑君里等-信号与系统（第3版·上册）.pdf#page=53|郑君里§1.8 分析方法]]。

### 例题与习题

下列9题为自测，可先做一遍再展开核对。

1. 求 $3[u(t+1)-u(t-1)]$ 与 $2(1/2)^n u[n]$ 的总能量和平均功率。
2. 求 $u[n]$ 的总能量和**双边**平均功率。
3. 令 $x(t)=u(t+1)-u(t-2)$；画出 $x(3-2t)$，给出新门的起止时刻。
4. 判断 $e^{j6\pi n/7}$、$\cos(\sqrt2\pi n)$ 是否周期；若是，给出基本周期。再给 $\cos(\pi n/2)+\cos(\pi n/3)$ 找一个公周期。
5. 把 $x(t)=e^{-t}u(t)$ 分为偶部和奇部，先按 $t\ne0$ 计算。
6. 计算全实轴上的 $\int (t^2+1)\delta(2-3t)\,dt$；说明 $\delta[2n-1]$ 为什么恒为0。再求 $u(t)-2u(t-1)+u(t-2)$ 的广义导数。
7. 判断 $y[n]=x[-n]$ 的六项性质，用具体时刻说明因果性，用移位试验说明时不变性。
8. $y[n]=x[n]-x[n-1]$ 为什么在全体双边序列上不可逆？若已知 $x[n]=0$（$n<0$），写出恢复公式。
9. 理想RC电路以电容电压为输出，$y(0^-)=0$，输入 $Vu(t)$。求 $t>0$ 的输出，并给出 $t=RC$ 时达到最终值的比例。

> [!faq]- 参考答案与关键步骤
> **1.** 矩形脉冲宽度为2，$E=3^2\cdot2=18$。离散序列的平方和为 $4\sum_{n=0}^\infty(1/4)^n=16/3$。两者总能量有限，平均功率均为0。
>
> **2.** 总能量发散；双边窗口 $[-N,N]$ 中有 $N+1$ 项等于1，故 $P=\lim_{N\to\infty}(N+1)/(2N+1)=1/2$。
>
> **3.** 旧边界为 $-1,2$。解 $3-2t=2$ 得左边界 $1/2$，解 $3-2t=-1$ 得右边界 $2$。门内为1，门外为0；端点值按 $u(0)$ 的约定读原式。
>
> **4.** 第一项频率比 $3/7$，基本周期7；第二项频率比 $1/\sqrt2$ 为无理数，非周期。最后两项各有周期4和6，12是一个公周期。
>
> **5.** 对 $t\ne0$，$x_{\mathrm e}(t)=\frac12 e^{-\lvert t\rvert}$，$x_{\mathrm o}(t)=\frac12\operatorname{sgn}(t)e^{-\lvert t\rvert}$。在 $t=0$，奇部为0，偶部等于原信号在此点的取值。
>
> **6.** 根是 $t=2/3$，面积因子是 $1/3$，所以积分为 $[1+(2/3)^2]/3=13/27$。离散式要求 $n=1/2$，没有整数根。分段信号在 $0,1,2$ 处分别跳变 $1,-2,1$，导数为 $\delta(t)-2\delta(t-1)+\delta(t-2)$。
>
> **7.** 有记忆、可逆、非因果、BIBO稳定、时变、线性。反褶两次回到原信号；在 $n=-1$ 要用 $x[1]$。延时输入再反褶给 $x[-n-n_0]$，反褶输出再延时给 $x[-n+n_0]$。
>
> **8.** 加任意常数序列不改变差分，未知常数无法从输出找回。已知负下标处为0时用 $x[n]=\sum_{k=0}^{n}y[k]$（$n\ge0$），其余为0。
>
> **9.** 对 $t>0$，$RCy'+y=V$，用 $y(0^+)=0$ 得 $y(t)=V(1-e^{-t/(RC)})$。在 $t=RC$ 达到最终值的 $1-e^{-1}\approx63.2\%$（$V\ne0$）。

### 计算实验

用Python标准库做三个小检查：等幅复指数的周期、频率加 $2\pi$ 后的样值、交替增益的移位反例。分母判据才是周期的理论依据；有限网格的比较只用于验算。

```python
from cmath import exp
from fractions import Fraction
from math import pi

n_grid = range(-8, 9)
ratio = Fraction(2, 5)  # Omega / (2*pi)
omega = 2 * pi * float(ratio)
period = ratio.denominator

def wave(n, frequency=omega):
    return exp(1j * frequency * n)

period_error = max(abs(wave(n + period) - wave(n)) for n in n_grid)
alias_error = max(abs(wave(n, omega + 2 * pi) - wave(n)) for n in n_grid)
assert period_error < 1e-12 and alias_error < 1e-12
assert all(abs(wave(k) - wave(0)) > 1e-12 for k in range(1, period))

def step(n):
    return int(n >= 0)

def alternating(signal, n):
    return (-1 if n % 2 else 1) * signal(n)

shift_then_system = alternating(lambda n: step(n - 1), 1)
system_then_shift = alternating(step, 0)
assert (shift_then_system, system_then_shift) == (-1, 1)
print(f"N0 = {period}")
print(f"frequency shift error: {alias_error:.2e}")
print(f"shift then system: {shift_then_system}; system then shift: {system_then_shift}")
```

预期输出：基本周期5、频率平移后的最大差为浮点舍入量级、两个移位顺序给出的值分别为 $-1$ 和 $1$。把交替增益改成恒为1，可以对照时不变的情形。

### 易错点与待解决问题

- **采样与量化**：分别改变时间变量和幅值的取值范围；连续时间信号允许跳变。
- **横轴变换**：用新自变量去解原波形的特征点；$x(2t-4)$ 的延时为2，不能按4来画。
- **能量和功率**：先平方取模，再做双边平均；周期波形可以只在一个周期算平均值，完整信号的总能量另判。
- **离散周期与频率**：$\Omega$ 按 $2\pi$ 同余；先把 $\Omega/(2\pi)$ 化为既约分数，再读分母。常数和恒零的退化情形单独看。
- **冲激尺度**：连续冲激保面积，所以要除以 $\lvert a\rvert$；离散冲激只看整数零点。阶跃求导时要保留跳变冲激。
- **系统性质**：线性、时不变、因果和稳定是不同测试；零输入零输出只能筛掉一部分非线性系统。可逆性必须写清输入集合与边界条件。
