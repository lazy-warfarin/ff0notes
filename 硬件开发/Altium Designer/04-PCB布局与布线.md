## 旧 31｜交互式与模块化布局

1. 在文件标签栏右键，选择**垂直分割**，并排显示原理图与 PCB。
2. 原记通过交叉选择，使在原理图选中的器件在 PCB 中对应选中。
3. 在设置的 `Navigation` 中，配置交叉选择对象；原记一般只选择“元件”。

快速排列所选器件：**工具 → 器件摆放 → 在矩形区域排列**，原记快捷键为 `TOL`。

## 旧 32｜PCB 布局常用操作

| 操作 | 原笔记记录 |
| --- | --- |
| 排列、对齐所选器件 | 在 PCB 页面选中器件后使用 `A` |
| 切换器件所在层 | 拖动状态下按 `L` |
| 将多个器件作为固定组合布局 | 多选器件，右键选择“联合”，从选中的器件中生成联合；原记快捷键为 `U` |
| 锁定器件 | 选中器件，在 `Location` 处锁定；具体属性位置待本机确认 |
| 隐藏全部飞线 | 原记布局时一般先隐藏全部飞线，快捷键为 `UHA` |

## 旧 33｜鼠线（飞线）与网络显示

- 从右下角打开 `PCB` 面板。
- 选择 `Nets`，将 `Normal` 改为 `Mask`，用于高亮网络。
- 原记另写“`UM`，多根拉线”，没有说明对象、前置选择及完整操作，保留该记法待本机验证。

旧标题为“鼠线的打开及关闭”，但正文未给出完整的开启、关闭命令；隐藏全部飞线的 `UHA` 记录见旧第 32 课。
