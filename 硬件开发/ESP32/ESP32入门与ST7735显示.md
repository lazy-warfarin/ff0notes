# ESP32 入门与 ST7735 显示

> [!info] 整理范围
> 由两篇资料入口合并而来。保留旧学习路线和参考链接，不把链接整理当作已经完成开发板、驱动或显示屏的实测。

## 开发环境与入门路线

旧笔记记录了两种 Arduino 开发方式：Arduino IDE，或 VS Code + PlatformIO + Arduino 框架；当时更偏向后者。关于 MicroPython 的取舍是当时的学习记录，不作为当前生态优劣结论。

- [ESP32 Arduino 入门教程（原收藏定位到第 37 集）](https://www.bilibili.com/video/BV1RM4y1a7J5/?p=37)
- 部分开发板通过 CP210x 芯片提供 USB 转串口功能；**先确认实际开发板的 USB/串口芯片，再选择驱动**，不要把 CP210x 驱动当作所有 ESP32 开发板的统一要求。
- [Silicon Labs CP210x USB to UART 驱动下载](https://www.silabs.com/developers/usb-to-uart-bridge-vcp-drivers?tab=downloads)
