# 数论路线图

目标：先理解质因子指数和同余，再掌握质数表、快速幂与逆元，最后区分运行时预处理和编译期生成。

## 阶段一：质因数分解与约数

- [[03-算法/数论/01-质因数分解与约数|质因数分解与约数]]

掌握试除上界、剩余质因子的处理，以及从指数推出约数个数、约数和、完全平方数和乘积末尾零。能够解释为什么 $1$ 返回空分解，而 $0$ 不适用。

配套练习：[[04-题库/Codeforces/2267C-GCD-Treasury|2267C GCD Treasury]]。

## 阶段二：模运算与快速幂

- [[03-算法/数论/02-模运算与快速幂|模运算性质、快速幂与逆元]]

掌握同余的加减乘性质、负余数规范化、乘法溢出处理和二进制快速幂。明确普通除法不能直接搬进模运算，逆元与指数缩减都有条件；用前缀余数连接整除问题与 DP。

## 阶段三：质数判定与筛法

- [[03-算法/数论/03-质数判定与筛法|试除判素、埃氏筛与线性筛 SPF]]

根据任务选择方法：单个数判定、生成整段质数表、大量有界整数分解。能够解释埃氏筛为什么从平方开始，线性筛为什么在遇到当前数的最小质因子后停止。

## 阶段四：非运行期的质数生成

- [[03-算法/数论/04-编译期质数生成|Rust const fn 与 C++ 编译期筛表]]
- [[03-算法/数论/05-质数计数与表长估计|质数计数与表长估计]]（配套：定容量、判断上界方向）

重点是“求值阶段”，而不是另一种筛法。能区分运行时预处理、首次使用初始化、语言内编译期求值和外部离线生成；知道固定上界、求值限制、表存储与查询边界。

配套的规模估计解决“表要开多大”：知道上界时估个数，知道个数时估上界；$\pi(x)\sim x/\ln x$ 只能估算，开数组必须用严格上界或精确计数。

## 关联练习

- [[05-题单/Codeforces/数论关联题单|复用现有卡片的数论关联题单]]

题单先从质因数分解与 GCD 贪心的基础应用开始，再进入数论与 DP 的综合迁移。题目使用集中题库里的唯一卡片，已通过状态与代码链接以卡片为准。

## 完成标准

- 能手算并用模板得到 $360=2^3\cdot3^2\cdot5$，以及 $\tau(360)=24$、$\sigma(360)=1170$。
- 能解释模 $6$ 下不能约掉因子 $2$，以及为什么不存在 $2$ 的逆元。
- 快速幂覆盖指数 $0$、模数 $1$；筛法覆盖上界 $0,1,2$ 和平方数 $49$。
- 能从 SPF 表分解整数，并说明查询上界和预处理成本。
- 能用 Rust 的常量上下文或 C++ 的 `constexpr` / `consteval` 生成固定质数表，而不是仅依赖优化器。
- 能说明编译期生成只省去运行时筛表，不会消除查表、存储和输入输出的开销。
- 能解释 $x/\ln x$ 在 $x>10$ 时是下界而不是上界，并用 $n(\ln n+\ln\ln n)$ 为前 $n$ 个质数定出筛表上界。
