# 动态规划总览

动态规划的核心不是套模板，而是把一个大问题拆成有重叠子问题的状态，并保证转移顺序能够覆盖所有依赖。

# DP基本要素

1. 最优子结构性质：原问题的最优解包含了子问题的最优解（或原问题最优解可由子问题最优解构造出来）
	如何证明最优子结构——**剪切—粘贴法**（cut-and-paste）（本质是反证）
	证明模板：
	1. 定义问题P和子问题P'
	2. 取原问题的一个最优解S
	3. 假设S‘不是子问题P’的最优解（存在S''比S'更优）
	4. 用S‘’替换S'
	5. **证明替换后仍可行且更优**（S''推出的S_new比原S更优）
	6. 推出矛盾
2. 重叠子问题：一个问题在递归求解时，会反复遇到**相同的小子问题**

## 四个问题

1. **状态是什么？** `dp[...]` 必须描述一个明确的子问题。
2. **如何转移？** 当前状态由哪些更小状态得到？
3. **如何初始化？** 空集、起点、不可达状态分别是什么？
4. **答案在哪里？** 可能是 `dp[n]`、一整行的最值，或所有终态的聚合。

## 通用检查表

- 状态是否包含了未来决策需要的全部信息？
- 转移是否覆盖“选”和“不选”等互斥情况？
- 不可达状态是否使用了不会污染答案的初值？
- 循环顺序是否满足依赖关系？
- 是否可以滚动数组、前缀最值、单调队列或分治优化？
