# 线性 DP

状态通常沿着数组、字符串或时间轴递推。重点是确定“处理到位置 `i` 时的最优值/方案数”。

## 建模

常见形式：

```text
dp[i] = 处理前 i 个元素后的答案
dp[i][state] = 处理前 i 个元素且处于 state 的答案
```

## 典型转移

- 只依赖前一项：`dp[i] <- dp[i - 1]`
- 依赖前两项：楼梯、打家劫舍
- 有限状态机：休息、工作、持有、未持有
- 维护前缀最优：`best[i] = max(best[i - 1], candidate)`

## 易错点

- 先决定状态含义，再决定数组下标。
- 负数场景不要把不可达状态初始化为 `0`。
- 如果转移依赖 `i - k ... i - 1`，考虑单调队列或滑动窗口。
