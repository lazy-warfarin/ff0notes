# 01 背包与完全背包

返回 [[03-算法/动态规划/02-背包DP/00-背包DP总览|背包 DP 总览]]。

## 适用场景

01 背包：每件物品最多选择一次，可选或不选。

完全背包：每种物品可以选择任意多次。

两者的题面结构几乎相同，关键区别是每件物品能否在容量转移后被再次使用。

## 核心思想

先写出不使用空间压缩的转移：

```text
f[i][j] = op(不选第 i 件物品, 选第 i 件物品)
```

01 背包只能从 `f[i - 1]` 转移；完全背包可以从已经处理过第 `i` 件物品的 `f[i]` 转移。

压缩成一维后，这个区别表现为容量循环方向：

- 01 背包倒序；
- 完全背包正序。

## 状态定义

设 `f[i][j]` 表示处理前 `i` 件物品、容量为 `j` 时的最优值或方案信息。

对 01 背包：

```text
f[i][j] = op(
    f[i - 1][j],
    f[i - 1][j - w_i] + v_i
)
```

对完全背包：

```text
f[i][j] = op(
    f[i - 1][j],
    f[i][j - w_i] + v_i
)
```

计数时把 `v_i` 从状态中省略，只统计方案数；可行性时把合并运算换成逻辑或。

## 转移方程

### 01 背包

$$
f_i[j]=\operatorname{op}\left(f_{i-1}[j],\ f_{i-1}[j-w_i]+v_i\right)
$$

压缩成一维数组：

```text
for each item (w, v):
    for j from C down to w:
        dp[j] = op(dp[j], dp[j - w] + v)
```

倒序保证 `dp[j - w]` 还没有包含当前物品。

常见变形：

```text
// 可行性
dp[j] |= dp[j - w]

// 计数
dp[j] = (dp[j] + dp[j - w]) % mod
```

### 完全背包

$$
f_i[j]=\operatorname{op}\left(f_{i-1}[j],\ f_i[j-w_i]+v_i\right)
$$

压缩成一维数组：

```text
for each item (w, v):
    for j from w to C:
        dp[j] = op(dp[j], dp[j - w] + v)
```

正序使 `dp[j - w]` 可以已经使用过当前物品，从而实现重复选择。

常见变形：

```text
// 可行性
dp[j] |= dp[j - w]

// 组合计数
dp[j] = (dp[j] + dp[j - w]) % mod
```

## 初始化与边界

- 最大值且不要求装满：通常令所有 `dp[j] = 0`；
- 最小值或恰好容量：令 `dp[0] = 0`，其余按目标设为正无穷或负无穷；
- 可行性：`dp[0] = true`，其余为 `false`；
- 计数：`dp[0] = 1`，其余为 `0`；
- 不超过容量求最值时，答案不一定是 `dp[C]`，要根据状态语义决定是否取前缀最值。

## 遍历顺序

| 类型 | 容量方向 | 原因 |
| --- | --- | --- |
| 01 背包 | `C` 到 `w` | 当前物品最多使用一次 |
| 完全背包 | `w` 到 `C` | 当前物品可以继续使用 |

循环顺序判断只看一件事：转移右侧是否需要读取当前层已经更新过的状态。

## 空间优化

01 背包和完全背包都可以从 `O(nC)` 压缩到 `O(C)`。

01 背包依靠倒序保留上一层状态；完全背包依靠正序让当前层继续参与转移。需要还原方案时，不能只保留压缩后的最值，需要额外记录选择或前驱。

## 复杂度

| 类型 | 时间复杂度 | 空间复杂度 |
| --- | --- | --- |
| 01 背包 | `O(nC)` | `O(C)` |
| 完全背包 | `O(nC)` | `O(C)` |

## 常见错误

- 把 01 背包容量写成正序，导致同一物品被重复使用。
- 把完全背包容量写成倒序，结果退化成 01 背包。
- 混淆“组合计数”和“排列计数”。
- 恰好容量仍把所有状态初始化为 `0`。
- 认为循环顺序只是模板，没有检查转移右侧读取的是哪一层。
