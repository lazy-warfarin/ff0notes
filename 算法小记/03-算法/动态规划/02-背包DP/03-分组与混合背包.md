# 分组与混合背包

返回 [[03-算法/动态规划/02-背包DP/00-背包DP总览|背包 DP 总览]]。

## 适用场景

分组背包：物品被分成若干组，每组最多选一个，或每组必须选一个。

混合背包：同一道题同时出现 01、完全和多重物品。

“同一种物品选多少件”是多重背包；“一组不同物品选哪一个”是分组背包。

## 核心思想

分组背包把一整组视为一次决策，当前组的所有选择都必须读取上一组状态。

混合背包不追求一套统一循环，而是先给每件物品确定类型，再分别套用对应转移。

## 状态定义

设第 `i` 组为 `G_i`，`f_i[j]` 表示处理完前 `i` 组、容量为 `j` 时的答案：

$$
f_i[j]=
\operatorname{op}\left(
f_{i-1}[j],\
\operatorname{op}_{x\in G_i,\ w_x\le j}
\left(f_{i-1}[j-w_x]+v_x\right)
\right)
$$

`f_{i-1}[j]` 表示整组不选。若题目要求每组必须选一个，就不能保留这个分支。

混合背包中，每件物品仍然用 `(w_i, v_i, limit_i)` 描述，只是 `limit_i` 的规则不同。

## 转移方程

### 分组背包

最稳妥的实现是显式保留上一组的 `prev`：

```text
for each group:
    cur = prev                       // 本组不选
    for j from 0 to C:
        for item (w, v) in group:
            if j >= w:
                cur[j] = op(cur[j], prev[j - w] + v)
    prev = cur
```

原地数组写法必须按“组 -> 容量倒序 -> 组内物品”执行。容量倒序保证组内物品读取的是上一组状态，不会叠加同一组中的多个物品。

每组必须选一个时，把 `cur` 先设为不可达，只保留组内选择分支。

### 混合背包

设当前物品的数量上限为 `limit_i`，统一形式为

$$
f_i[j]=
\operatorname{op}_{0\le k\le \min(limit_i,\lfloor j/w_i\rfloor)}
\left(f_{i-1}[j-k w_i]+k v_i\right)
$$

实现时按类型分别处理：

```text
for item (w, v, type):
    if type == 01:
        for j from C down to w:
            dp[j] = op(dp[j], dp[j - w] + v)
    else if type == complete:
        for j from w to C:
            dp[j] = op(dp[j], dp[j - w] + v)
    else:
        use bounded-knapsack transition for count
```

## 初始化与边界

- 分组背包的“不选本组”来自上一组状态，不能来自已经更新的当前组。
- 每组恰好选一个时，未成功选择的容量状态必须保持不可达。
- 混合背包逐件判断类型，计数、可行性和最值沿用各自的初始化规则。
- 若一组包含多个合法组合，组合本身先枚举好，再统一做分组转移。

## 遍历顺序

| 类型 | 典型顺序 | 原因 |
| --- | --- | --- |
| 分组背包 | 组 -> 容量倒序 -> 组内物品 | 每组最多选一个 |
| 每组必选 | 组 -> 容量状态 -> 组内物品 | 不允许跳过整组 |
| 混合背包 | 按物品类型分别处理 | 不同物品的使用次数不同 |

## 空间优化

分组背包可以原地使用 `O(C)`，也可以保留 `prev` 与 `cur` 使用 `O(2C)`。当前组选择较复杂时，双数组更不容易写错。

混合背包通常仍能把第一维压缩到 `O(C)`，但每种物品都要检查自己的容量方向和辅助数组。

## 复杂度

| 类型 | 时间复杂度 | 空间复杂度 |
| --- | --- | --- |
| 分组背包 | `O(C * 组内物品总数)` | `O(C)` 或 `O(2C)` |
| 混合背包 | 各物品转移复杂度之和 | `O(C)` 或额外辅助数组 |

## 常见错误

- 分组背包写成“组 -> 组内物品 -> 容量”，导致同一组选中多个物品。
- 原地更新时没有倒序容量，转移右侧混入当前组状态。
- 每组要求必选，却保留了“不选本组”的分支。
- 混合背包把所有物品统一套用 01 或完全背包的循环方向。
