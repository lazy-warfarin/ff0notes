# 计数与方案

返回 [[03-算法/动态规划/02-背包DP/00-背包DP总览|背包 DP 总览]]。有限次数的计数转移见 [[03-算法/动态规划/02-背包DP/02-多重背包|多重背包]]。

## 适用场景

- 统计满足容量限制的方案数；
- 区分或合并不同的选择顺序；
- 输出一组达到最优值的具体物品；
- 题目还带有排序、截止时间或严格改进条件。

计数题先明确一个方案由什么决定：选择了哪些物品，还是按什么顺序选择。

## 核心思想

背包计数的状态含义仍然是容量，但合并运算从 `max` 变成加法。循环顺序决定了每件物品是被当作一个可重复的决策层，还是一个会读取当前层状态的决策层。

方案还原不能只保存最终最值。需要在转移发生时留下“当前状态选了哪个物品或哪个前驱”，并保证回溯路径唯一且合法。

## 状态定义

设 `dp[j]` 表示容量恰好为 `j` 的方案数。初始化：

```text
dp[0] = 1
其余 dp[j] = 0
```

`dp[0] = 1` 表示空方案。若题目统计容量不超过 `C` 的方案，答案通常是

$$
\sum_{j=0}^{C} dp[j]
$$

而不是只取 `dp[C]`。

对于方案还原，可以保留 `dp[i][j]` 和 `take[i][j]`。也可以记录 `prev_capacity[j]` 与选择物品，但要确保压缩后仍能唯一回溯。

## 转移方程

### 01 背包计数

每件物品最多使用一次，容量倒序：

```text
dp[0] = 1
for each item (w, v):
    for j from C down to w:
        dp[j] = (dp[j] + dp[j - w]) % mod
```

这里统计的是选择物品的组合，不区分选择顺序。

### 完全背包的组合计数

物品外层、容量正序：

```text
dp[0] = 1
for each item (w, v):
    for j from w to C:
        dp[j] = (dp[j] + dp[j - w]) % mod
```

同一组的物品先固定处理顺序，因此 `1 + 2` 和 `2 + 1` 只算一次。

### 完全背包的排列计数

若不同选择顺序算不同方案，容量放在外层：

```text
dp[0] = 1
for j from 1 to C:
    for each item (w, v):
        if j >= w:
            dp[j] = (dp[j] + dp[j - w]) % mod
```

这段代码对应物品可以无限使用的情况。若是 01 物品且顺序有意义，只靠一维容量状态会重复使用物品，还需要额外的已选状态或集合状态。

### 方案还原

以排序后的 01 背包为例，先按截止时间排序，再用二维状态和选择表：

```text
for i in 1..n:
    for j in 0..C:
        dp[i][j] = dp[i - 1][j]
        if j >= w[i] and dp[i - 1][j - w[i]] + v[i] > dp[i][j]:
            dp[i][j] = dp[i - 1][j - w[i]] + v[i]
            take[i][j] = true
```

只在严格改进时记录选择，避免相等值覆盖原本可回溯的路径。最后从终态向前检查 `take[i][j]`，选入物品后把容量减去对应费用。

## 初始化与边界

- 计数初始化 `dp[0] = 1`，其他容量为 `0`。
- 恰好容量统计取 `dp[C]`；不超过容量统计取前缀和。
- 方案数很大时边转移边取模，避免整数溢出。
- 空方案是否合法要由题意决定；若容量必须非空，最后应排除空方案。
- 输出方案时，终态可能不止一个容量位置，要先确认题目要求的是恰好容量还是最优值。

## 遍历顺序

| 目标 | 典型顺序 | 统计结果 |
| --- | --- | --- |
| 01 组合计数 | 物品 -> 容量倒序 | 每件物品最多一次，不区分顺序 |
| 完全组合计数 | 物品 -> 容量正序 | 同一组合只统计一次 |
| 完全排列计数 | 容量 -> 物品 | 不同顺序分别统计 |
| 方案还原 | 正向转移，逆向回溯 | 保存选择与前驱 |

## 空间优化

计数通常可以压缩到 `O(C)`。如果只输出方案数，不需要保留历史层；如果需要还原方案，建议保留二维状态或额外的选择表，空间为 `O(nC)`。

排序后的 01 背包可以在二维数组中记录 `take`，也可以为每个状态保存前一个物品编号。压缩后只保存一个布尔值时，必须确认回溯不会读到被覆盖的状态。

## 复杂度

| 类型 | 时间复杂度 | 空间复杂度 |
| --- | --- | --- |
| 01 组合计数 | `O(nC)` | `O(C)` |
| 完全组合或排列计数 | `O(nC)` | `O(C)` |
| 二维方案还原 | `O(nC)` | `O(nC)` |

## 常见错误

- 把“组合”误写成“排列”，或者反过来。
- 01 物品的排列计数直接套完全背包的容量外层写法，导致物品被重复使用。
- 求不超过容量的方案数时只取 `dp[C]`。
- 多重背包计数直接套普通二进制拆分，造成同一选择被多次表示。
- 方案还原只在最终位置回溯，却没有保存中间选择。
- 相等值时覆盖选择，导致回溯到不合法的前驱。
- 方案数很大却没有取模，或使用了不够大的整数类型。
- 543A 这类题不能把每个程序员当成只能选一次：同一程序员可以写多行，是按程序员分组处理的二维完全背包式计数。
