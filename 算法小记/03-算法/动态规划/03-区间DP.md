# 区间 DP

状态表示一个连续区间 `[l, r]` 的答案，通常枚举区间长度，再枚举分割点或端点匹配关系。

## 常见形式

```text
dp[l][r] = 区间 [l, r] 的最优答案
dp[l][r] = min/max(dp[l][k] + dp[k + 1][r] + cost)
```

## 遍历顺序

通常按区间长度从短到长：

```text
for len = 1..n:
    for l:
        r = l + len - 1
```
