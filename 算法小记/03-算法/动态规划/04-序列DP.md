# 序列 DP

序列 DP 关注前缀、子序列或最后一个元素。LIS、最长公共子序列和连续子段都属于常见变体。

## 关键区别

- 子数组/连续子段：状态通常必须包含“以 `i` 结尾”。
- 子序列：可以跳过元素，常见状态是长度或最后一个值。
- 需要恢复方案时，额外记录前驱位置。
