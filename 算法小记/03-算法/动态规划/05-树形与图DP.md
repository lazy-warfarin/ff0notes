# 树形与图 DP

树形 DP 通过 DFS 聚合子树信息；DAG DP 按拓扑序处理依赖。

## 树形 DP

先定义 `dp[u]` 表示子树 `u` 的答案，再从子节点向父节点合并。需要全局答案或换根时，再进行第二次 DFS。

## DAG DP

当图无环时，拓扑序保证前驱已经计算，可以把最长路、计数等问题转成线性递推。
