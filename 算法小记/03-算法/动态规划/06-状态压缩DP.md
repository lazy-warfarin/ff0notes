# 状态压缩 DP

当元素数量较小、状态是“已经选择了哪些元素”时，用 bitmask 表示集合。

## 常见状态

```text
dp[mask]                 已选择集合 mask 的答案
dp[mask][last]           已选择集合且最后选择 last
dp[mask][remainder]      集合选择与模数状态
```

复杂度通常为 `O(2^n * n)` 或 `O(2^n * n^2)`，先确认 `n` 足够小。
