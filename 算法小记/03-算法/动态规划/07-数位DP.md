# 数位 DP

数位 DP 用于统计 `[0, x]` 中满足数字限制的数。典型状态包含当前位置、前导零、是否贴上界，以及题目要求的附加状态。

```text
dfs(pos, state, tight, started)
```

## 注意事项

- `tight` 表示当前前缀是否仍等于上界前缀。
- 前导零是否参与状态，必须按题意决定。
- 统计 `[L, R]` 时通常计算 `count(R) - count(L - 1)`。
