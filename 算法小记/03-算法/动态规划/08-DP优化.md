# DP 优化

当朴素转移是 `O(n^2)` 或更高时，先识别转移中的结构，再选择优化工具。

## 常见工具

- 前缀最值、后缀最值
- 单调队列
- 分治优化
- 决策单调性
- 凸包优化
- 斜率优化
