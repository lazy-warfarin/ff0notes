# 质因数分解与约数

## 适用场景

- 将乘法问题转为质因子指数的加法问题：乘积末尾零、完全平方数、最大公约数和最小公倍数。
- 求一个正整数的约数个数、约数和，或枚举全部约数。
- 条件只关心“能否被某个质数整除”时，仅保留不同质因子；不必记录指数，也不必枚举全部约数。
- 少量整数用试除法；大量有界整数用 [[03-算法/数论/03-质数判定与筛法|最小质因子表 SPF]]。

## 核心思想

### 算术基本定理

质数是大于 $1$、恰有 $1$ 和自身两个正约数的整数。每个 $n\ge2$ 都能唯一分解为不同质数的幂的乘积（忽略排列顺序）：

$$
n=\prod_{i=1}^{k}p_i^{\alpha_i},\qquad \alpha_i\ge1.
$$

$1$ 的质因数分解是空乘积，不是“质因子为 $1$”。例如：

$$
360=2^3\cdot3^2\cdot5.
$$

### 为什么只试除到平方根

若剩余数 $m$ 是合数，就至少有一个质因子不超过 $\sqrt m$。从小到大彻底除尽每个因子后，一旦当前候选因子满足 $p^2>m$，若 $m>1$，它就只能是一个剩余质因子。

这里的 $m$ 会随除法不断变小，不必一直试到原数的平方根。代码用 `p <= n / p` 判断，避免直接计算 `p * p` 溢出。

## 状态定义

这里不是 DP；“状态”指循环中需要维护的信息：

- $n_0$：原始正整数。
- $m$：尚未分解的剩余部分，代码里用可变参数 `n` 表示。
- $p$：当前候选因子。
- $(p_i,\alpha_i)$：已经提取出的质因子及指数。

循环不变量：$n_0=\left(\prod p_i^{\alpha_i}\right)m$，且所有小于当前候选 $p$ 的质因子均已从 $m$ 中除尽。

## 转移方程

### 质因子指数如何使用

对正整数 $a,b$，令缺失质因子的指数为 $0$，则：

$$
v_p(ab)=v_p(a)+v_p(b),
$$

$$
v_p(\gcd(a,b))=\min(v_p(a),v_p(b)),\qquad
v_p(\operatorname{lcm}(a,b))=\max(v_p(a),v_p(b)).
$$

- $n$ 是完全平方数，当且仅当所有质因子指数均为偶数；$1$ 也满足。
- 正整数 $n$ 是某个正整数的 $t$ 次幂（$t\ge2$），当且仅当所有质因子指数均能被 $t$ 整除。
- 十进制乘积末尾零的数量为 $\min(v_2(n),v_5(n))$，不必实际算出巨大乘积。

### 约数个数

每个正约数都唯一对应一组指数 $0\le\beta_i\le\alpha_i$，所以：

$$
\tau(n)=\prod_{i=1}^{k}(\alpha_i+1).
$$

例如 $\tau(360)=(3+1)(2+1)(1+1)=24$。

### 约数和

$$
\sigma(n)=\prod_{i=1}^{k}(1+p_i+p_i^2+\cdots+p_i^{\alpha_i}).
$$

在普通整数运算中，也可把每一项写为 $\dfrac{p_i^{\alpha_i+1}-1}{p_i-1}$；例如 $\sigma(360)=15\cdot13\cdot6=1170$。

> [!warning] 取模后的除法不是整数除法
> 求约数和模 $M$ 时，不能对分子取模后直接除以 $p_i-1$。只有分母与 $M$ 互质时才能使用逆元；否则可以逐项递推几何和。详见 [[03-算法/数论/02-模运算与快速幂|模运算与逆元]]。

### 枚举约数

从列表 `[1]` 开始。每处理一个 $p^\alpha$，先保存旧列表，再把每个旧约数分别乘以 $p,p^2,\ldots,p^\alpha$ 后加入；原列表对应乘 $p^0$。不要一边扩展列表，一边把刚加入的项当作旧约数重复扩展。

## 初始化与边界

- 输入要求 $n\ge1$。$n=1$ 返回空分解，$\tau(1)=\sigma(1)=1$。
- $0$ 不存在这种有限质因数分解；下面的函数明确拒绝 $0$。
- 负数先单独处理符号，再分解其绝对值；有符号最小值的绝对值可能溢出，不能无条件使用普通 `abs()`。
- 提取一个质因子时必须反复除尽，指数不是只加一次。
- 循环结束后的剩余数若大于 $1$，必须补入答案，指数为 $1$。

## 遍历顺序

先试除 $2$，之后只枚举奇数。虽然奇数候选里也含合数，但合数的更小质因子已经被除尽，因此不会被错误记录成质因子。

```rust
fn factorize(mut n: u64) -> Vec<(u64, u32)> {
    assert!(n >= 1, "zero has no finite prime factorization");
    let mut factors = Vec::new();
    let mut p = 2_u64;

    while p <= n / p {
        if n % p == 0 {
            let mut exponent = 0_u32;
            while n % p == 0 {
                n /= p;
                exponent += 1;
            }
            factors.push((p, exponent));
        }
        p += if p == 2 { 1 } else { 2 };
    }

    if n > 1 {
        factors.push((n, 1));
    }
    factors
}
```

例：`factorize(360)` 得到 `[(2, 3), (3, 2), (5, 1)]`，`factorize(1)` 得到空数组，`factorize(49)` 得到 `[(7, 2)]`。

## 空间优化

- 只需要约数个数、某个质因子的指数或指数奇偶时，可以边分解边统计，不保存完整分解。
- 只关心少量固定质因子时，直接反复除这些质数。例如末尾零只统计 $2$ 和 $5$。
- 多次查询且 $n\le N$ 时，用 SPF 表换时间；不要给每次查询重新筛一次。

## 复杂度

设原数为 $n_0$，不同质因子的个数为 $k$：

- 逐个候选试除最坏时间 $O(\sqrt{n_0})$，常见最坏情况是输入本身为大质数。
- 输出占 $O(k)$ 空间，除输出外的额外空间为 $O(1)$。
- 已有覆盖到 $\sqrt{n_0}$ 的完整质数表时，可只试除质数；不能把一张过短的表用完，就断定剩余数是质数。
- SPF 法预处理时间 $O(N)$、空间 $O(N)$，单次分解至多进行 $O(\log n)$ 次除法，见筛法笔记。

> [!note] 类型能装下，不代表时间能承受
> 这个函数使用 `u64` 避免过窄的输入类型，但不意味着它能高效处理任意 64 位大整数。若平方根级试除超时，应另学 Miller–Rabin 与 Pollard–Rho，而不是简单换大类型。

## 常见错误

- 把 $1$ 当质数，或给 $1$ 添加一个“质因子 $1$”。
- 漏掉试除结束后大于 $1$ 的剩余质因子。
- 用 `p * p <= n` 却没有检查乘法是否会溢出。
- 将“不同质因子数量”和“计重的质因子数量”混淆：$12=2^2\cdot3$，前者是 $2$，后者是 $3$。
- 求约数和取模时直接做除法，或在枚举约数时重复使用本轮新增元素。
