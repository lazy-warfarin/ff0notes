# 模运算与快速幂

## 适用场景

- 大数计数、乘积或幂只要求模某个正整数后的结果。
- 只关心整除性、余数状态，或用前缀余数判断一段区间和能否被整除。
- 处理模意义下的除法、逆元，以及质数模数下的幂运算。

## 核心思想

### 同余与标准余数

固定 $m\ge1$，定义：

$$
a\equiv b\pmod m\quad\Longleftrightarrow\quad m\mid(a-b).
$$

数学中通常把余数规范到 $[0,m-1]$。Rust 和 C++ 的 `%` 对负数可能得到负余数，不应直接把结果当作数组下标。Rust 对正模数可以使用 `x.rem_euclid(m)`。

### 可以随时取模的运算

下式中每次取模均指规范化余数：

$$
(a+b)\bmod m=((a\bmod m)+(b\bmod m))\bmod m,
$$

$$
(a-b)\bmod m=((a\bmod m)-(b\bmod m))\bmod m,
$$

$$
(ab)\bmod m=((a\bmod m)(b\bmod m))\bmod m.
$$

因此，加减乘组成的整数多项式、非负整数次幂可以逐步取模，避免整数无限增长。**取模仍不能修复已经发生的机器整数溢出**，乘法和加法的中间结果也要能装下。

### 不能直接保留的运算与关系

- **普通除法**：模 $7$ 时，$(10/2)\bmod7=5$，但 $(10\bmod7)/2=1$。
- **大小关系**：$8>6$，但模 $7$ 后 $1<6$；不能把求最大值的 DP 状态先取模再比较。
- **直接约掉因子**：$2\cdot1\equiv2\cdot4\pmod6$，但 $1\not\equiv4\pmod6$。

更准确的约分规律是：令 $d=\gcd(c,m)$，则

$$
ca\equiv cb\pmod m\quad\Longleftrightarrow\quad a\equiv b\pmod{m/d}.
$$

只有 $\gcd(c,m)=1$ 时，才能约掉 $c$ 且保持模数仍为 $m$。

## 状态定义

快速幂维护三个变量，不是 DP：

- $r$：已经累积的答案。
- $b$：当前二进制位对应的底数幂。
- $e$：尚未处理的非负指数。

若原始参数是 $a_0,e_0$，循环不变量为：

$$
r\cdot b^e\equiv a_0^{e_0}\pmod m.
$$

## 转移方程

### 二进制快速幂

若当前 $e$ 为奇数，先令 $r\leftarrow rb\bmod m$。随后统一执行：

$$
b\leftarrow b^2\bmod m,\qquad e\leftarrow\lfloor e/2\rfloor.
$$

等价于将指数拆成二进制；每一位只需要常数次模乘。

### 模逆元与除法

对 $m\ge2$，若存在 $x$ 使 $ax\equiv1\pmod m$，称 $x$ 为 $a$ 的模逆元，记作 $a^{-1}$。它存在当且仅当 $\gcd(a,m)=1$。

- 已知逆元时，模意义下“除以 $a$”改为乘 $a^{-1}$。
- 一般模数：扩展欧几里得求出 $ax+my=d$；只有 $d=1$ 时，$x$ 的规范化余数才是逆元。
- 例如 $3^{-1}\equiv5\pmod7$；$2$ 在模 $6$ 下没有逆元。

扩展欧几里得的回代来自：若 $bx'+(a\bmod b)y'=d$，则

$$
x=y',\qquad y=x'-\lfloor a/b\rfloor y'.
$$

这段公式按非负整数的欧几里得除法理解；终止于 $b=0$ 时取 $(d,x,y)=(a,1,0)$。

### 费马小定理与欧拉定理

当 $p$ 是质数且 $p\nmid a$ 时：

$$
a^{p-1}\equiv1\pmod p,\qquad a^{-1}\equiv a^{p-2}\pmod p.
$$

一般地，当 $m\ge2$ 且 $\gcd(a,m)=1$ 时：

$$
a^{\varphi(m)}\equiv1\pmod m,
\qquad
\varphi(m)=m\prod_{p\mid m}\left(1-\frac1p\right).
$$

乘积遍历不同质因子，分解方法见 [[03-算法/数论/01-质因数分解与约数|质因数分解]]。在这些互质条件下，非负指数才可按对应的 $p-1$ 或 $\varphi(m)$ 缩减。

> [!warning] 指数不能无条件取模
> $2^4\bmod8=0$，但 $\varphi(8)=4$，若直接把指数变成 $4\bmod4=0$，会得到 $2^0\bmod8=1$。底数与模数不互质时，不能直接套欧拉降幂；也不能把任意合数模数下的逆元写成 $a^{m-2}$。

### 前缀余数与整除

令 $s_i$ 为前 $i$ 个数的和，$s_0=0$。区间 $[l,r]$ 的和被 $m$ 整除，当且仅当：

$$
s_r\equiv s_{l-1}\pmod m.
$$

因此，$n\ge m$ 时，$n+1$ 个前缀余数落入 $m$ 种余数类，必有两个相同，从而存在非空连续子数组的和被 $m$ 整除。连续子数组也是一种子序列，但反过来不成立；不要混淆两类问题。

## 初始化与边界

- 模数必须 $m>0$；模 $0$ 无定义。模 $1$ 时所有结果均为 $0$。
- 快速幂初始化 $r=1\bmod m$，使指数 $0$、模数 $1$ 都得到正确结果。
- 下方函数对指数 $0$ 返回乘法空积的余数，包括把 `pow_mod(0, 0, m)` 定义成 `1 % m`；具体题目若另有约定，应在调用前处理。
- 逆元章节使用 $m\ge2$；质数逆元函数要求调用者保证 $p$ 为质数，且先排除 $a\equiv0\pmod p$。
- 负指数不是下面函数的输入；若题目允许负指数，需要先确认底数存在逆元。

## 遍历顺序

从指数的最低二进制位开始处理。下方用 `u128` 保存两个 `u64` 的乘积，支持整个 `u64` 正模数范围的模乘。

```rust
fn mul_mod(a: u64, b: u64, m: u64) -> u64 {
    assert!(m > 0);
    ((a as u128 * b as u128) % m as u128) as u64
}

fn pow_mod(mut a: u64, mut e: u64, m: u64) -> u64 {
    assert!(m > 0);
    a %= m;
    let mut result = 1 % m;
    while e > 0 {
        if e & 1 == 1 {
            result = mul_mod(result, a, m);
        }
        a = mul_mod(a, a, m);
        e >>= 1;
    }
    result
}

// 前置条件：p 是质数。本函数不会自行判定 p 的素性。
fn inv_prime(a: u64, p: u64) -> Option<u64> {
    assert!(p >= 2);
    if a % p == 0 {
        None
    } else {
        Some(pow_mod(a, p - 2, p))
    }
}
```

例：`pow_mod(2, 10, 1_000) == 24`，`pow_mod(123, 0, 1) == 0`，`inv_prime(3, 7) == Some(5)`，`inv_prime(14, 7) == None`。

处理负余数和模加法时，也要照顾中间类型：

```rust
fn normalize_mod(x: i64, m: i64) -> i64 {
    assert!(m > 0);
    x.rem_euclid(m)
}

fn add_mod(a: u64, b: u64, m: u64) -> u64 {
    assert!(m > 0);
    ((a as u128 + b as u128) % m as u128) as u64
}
```

C++ 常写 `(x % m + m) % m` 规范化负余数，但当 $m$ 接近有符号类型上限时，加法仍可能溢出；更稳妥的做法是先算余数，仅在其为负时再加 $m$。大模数下模乘可用编译器支持的 `unsigned __int128`，不要假定普通 64 位乘法足够。

## 空间优化

快速幂只维护底数、指数和答案，额外空间 $O(1)$。与其计算完整的 $a^e$ 后取模，不如每次乘法后立即取模。

多组询问若模数固定，可按题目需要预处理阶乘、逆阶乘等；但必须先检查逆元存在条件，不把“模数是质数”误解成“任何数都有逆元”。

## 复杂度

- 固定宽度整数模乘按 $O(1)$ 计，快速幂时间 $O(\log(e+1))$，空间 $O(1)$。
- 质数模数下用费马小定理求单个逆元：时间 $O(\log p)$，空间 $O(1)$。
- 扩展欧几里得求逆元：除法次数 $O(\log m)$，递归版还需 $O(\log m)$ 栈空间；大整数环境须另计每次算术的成本。
- 用数组统计前缀余数：处理时间 $O(n)$，初始化与空间 $O(m)$；使用哈希表可只记录出现的余数。

## 常见错误

- 乘法先溢出，随后才取模，误以为最终余数小就不会出错。
- 把负数 `%` 的结果直接作为下标，或无条件用加模数的写法导致加法溢出。
- 在最优值尚需比较大小时取模，破坏大小关系。
- 不检查互质条件就约分、求逆元或缩减指数。
- 求非空子集的余数可达性时，把空集对应的余数 $0$ 当作已经找到合法方案。
- 使用多测试用例时忘记清空余数计数，或遗漏空前缀 $s_0$。
