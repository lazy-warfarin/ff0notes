# 1690G Count the Trains

> [Codeforces 1690G - Count the Trains](https://codeforces.com/problemset/problem/1690/G)
>
> 元数据核对：2026-10-26，title / rating / tags 来自 [Codeforces 官方 problemset API](https://codeforces.com/api/problemset.problems)，题意和约束按官方题面核对。作为手写红黑树的接口练习，不代表官方指定这一实现。

## 题意摘要

有 $n$ 节向左行驶的车厢，第 $i$ 节的最高速度为 $a_i$，不能快于它前面的车厢；最终相邻且速度相同的车厢组成一列火车。每次令一个 $a_k$ 减少 $d$，输出变化后的火车列数，修改累积生效。

单组 $1\le n,m\le10^5$，$0\le a_i\le10^9$、$0\le d\le a_k$；所有测试的 $n$ 之和、$m$ 之和分别不超过 $10^5$。

## 识别信号

- 最终速度是前缀最小值 $v_i=\min(a_1,\ldots,a_i)$，火车边界对应它严格下降的位置。
- 维护边界下标的有序集合，需要找不超过某位置的最大边界、严格后继、插入及删除，不需要第 $k$ 小。
- 使用手写红黑树时存的是**下标**，不要让比较器依赖会变动的速度数组。
- 单次修改可能删掉多个边界，需要均摊分析，不能直接宣称每次业务修改都只花 $O(\log n)$。

关联笔记：[[02-数据结构/树/01-红黑树|红黑树：删除与前驱后继]]。

## 状态与转移

用集合 $B$ 存边界：位置 $1$ 一定在内；之后只有 $a_i<\min(a_1,\ldots,a_{i-1})$ 才加入。边界上的速度严格递减，答案为 $|B|$。

一次修改可以这样处理：

1. 修改前先找到 $p=\max\{i\in B:i\le k\}$，保存旧实际速度 $v=a_p$；再令 $a_k\leftarrow a_k-d$。先保存可避免 $p=k$ 时旧速度被覆盖。
2. 若新 $a_k\ge v$，它没有降低原来的实际速度，边界不变。
3. 否则把 $k$ 加入 $B$，若本来就是边界则保持唯一；重复查询 $k$ 的严格后继 $j$，只要 $a_j\ge a_k$ 就删除 $j$，直到后继不存在或速度严格更小。
4. 输出 $|B|$。相等速度属于同一列火车，所以删除条件必须包含等号。

位置 $k$ 成为新边界后，它覆盖到下一个速度更小的边界之前；被覆盖的旧边界失效。每条消息至多新插入一个边界，所有成功删除的次数不会超过初始边界数加总插入次数。

## 复杂度

- 单次消息若删除 $r$ 个边界，时间为 $O((r+1)\log(n+1))$，不是逐次最坏对数。
- 一组总时间 $O((n+m)\log(n+1))$，因为边界的总插入 / 删除次数为 $O(n+m)$。
- 活跃集合空间 $O(n)$；结点池若不回收，累计空间为 $O(n+m)$，回收复用后按峰值活跃槽位控制；另计数组和输入缓冲。
