# 蓝桥杯 C++ 研究生组国一训练计划

> 目标：在 12 周内建立研究生组所需的算法覆盖面、限时解题能力和稳定拿分能力。  
> 每天约 6 个题目单元，默认投入 4 小时以上。  
> 题源以蓝桥杯省赛/国赛真题为主，Codeforces、洛谷、AcWing 用于补齐专题和拔高。

具体到每天的六题安排见：[[蓝桥杯-C++研究生组-12周每日具体题单|12周每日具体题单]]。

## 一、使用说明

### 1. 题目单元的定义

每天的“6 题”按 6 个训练单元计算，不要求全部是新题：

1. 基础或模板题：20—30 分钟
2. 同专题中档题：35—45 分钟
3. 同专题中档题：35—45 分钟
4. 综合迁移题：45—60 分钟
5. 研究生组挑战题：60—90 分钟
6. 错题重做、模板默写或代码复盘：30—45 分钟

整套真题可以折算为 6 个单元，但必须记录每道题的得分、耗时和失分原因。

### 2. 统一提交前检查

- [ ] 数据范围是否支持当前复杂度
- [ ] 数组、图、DP 状态是否完整初始化
- [ ] 空集、单点、全相等、极值和不可达情况是否处理
- [ ] `int` 是否会溢出，乘法是否需要 `long long`
- [ ] 是否误把有向图当成无向图，或反过来
- [ ] 是否存在死循环、递归爆栈、重复计算
- [ ] 结果填空题是否保留中间推导和可复核过程

## 四、专项题单

### 1. 基础建模与复杂度

- 枚举、模拟、日期、进制、格式化
- 排序、前缀和、差分、离散化
- 二分答案、双指针、滑动窗口
- 贪心与交换论证
- 复杂度分析和边界构造

### 2. 搜索与状态空间

- DFS、BFS、连通块、网格搜索
- 回溯与剪枝
- 记忆化搜索
- 双向 BFS
- 迭代加深
- 启发式搜索与状态压缩搜索

### 3. 动态规划

- 线性 DP、背包 DP
- LIS、LCS、编辑距离
- 区间 DP
- 树形 DP、换根 DP
- 状压 DP
- 数位 DP
- 计数 DP、概率 DP
- 单调队列优化
- bitset 优化
- 分治优化和斜率优化基础

### 4. 图论

- 并查集、最小生成树
- Dijkstra、Bellman-Ford、Floyd
- 拓扑排序和 DAG DP
- 二分图判定与匹配
- SCC
- 割点与桥
- 差分约束
- LCA、DFS 序、树上差分
- 最大流、最小割、费用流基础

### 5. 数据结构

- 堆、ST 表
- 树状数组
- 线段树与懒标记
- Trie
- 莫队
- 可持久化结构基础
- 平衡树或 Treap 基础

### 6. 字符串

- 字符串哈希
- KMP
- Z 函数
- Manacher
- Trie
- AC 自动机
- 后缀数组或后缀自动机基础

### 7. 数论、组合与线性代数

- 最大公约数、扩展欧几里得
- 筛法、欧拉函数、快速幂
- 逆元、组合数、Lucas
- 容斥
- CRT
- 矩阵快速幂
- 高斯消元
- Nim 与常见博弈

### 8. 其他综合能力

- 构造
- 位运算
- 计算几何基础
- 概率与期望
- 多专题综合题
- 从暴力到正解的部分分设计
