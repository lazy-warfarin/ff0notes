# 线段树路线图

目标：先掌握“区间二分 + 信息合并”，再理解懒标记的下传与组合，最后学习自定义摘要和进阶结构的适用范围。知识点放在 `02-数据结构/线段树/`，与树状数组专题并列，不再额外套一层“高级数据结构”。

## 阶段一：单点修改与区间查询

- [[02-数据结构/线段树/01-线段树基础|线段树基础]]

能区分原数组下标与树结点编号，独立完成建树、单点赋值、区间和与最大最小值查询。理解查询 $[3,5]$ 可以直接合并 $[3,4]$ 与 $[5,5]$，不需要先求两个前缀再相减。

## 阶段二：区间修改与懒标记

- [[02-数据结构/线段树/02-懒标记与区间更新|区间加法、区间赋值与懒标记]]

先掌握纯加法的 `apply`、`push`、`pull`，再加入赋值。能解释“当前结点统计已更新，孩子暂时未更新”的状态，以及为什么先赋值后加与先加后赋值不同。

本篇提供同时维护区间和、最小值、最大值的完整 Rust 模板；只做一种查询时可以删减字段。

## 阶段三：自定义信息与最大子段和

- [[02-数据结构/线段树/03-信息合并与最大子段和|信息合并、结合律与最大子段和]]

学会用 `sum`、`pref`、`suff`、`best` 合并最大非空子段和；能区分结合律与交换律，理解查询时为什么必须保持左右顺序。再用局部排名分类和体会自定义摘要的迁移。

关联练习复用已有题卡，不是最大子段和模板题：

- [[04-题库/Codeforces/85D-Sum-of-Medians|85D Sum of Medians]]

## 阶段四：选型与进阶入门

- [[02-数据结构/线段树/04-区间问题选型与进阶|静态/动态选型、值域树与进阶方向]]

先区分“全部改完才查”和“边改边查”，再比较前缀和、差分、BIT、ST 表与线段树。进阶部分说明以下概念，不把概念介绍当成已完成的实现：

1. 权值线段树：按值域维护频率，沿左右计数找第 $k$ 小。
2. 扫描线与离散化：区分坐标排名与几何长度。
3. 动态开点：只为实际访问的路径建立结点。
4. 可持久化：路径复制保留历史版本，前缀频率版本差用于区间第 $k$ 小。
5. 树套树与 Segment Tree Beats：了解识别信号，复杂度按具体操作单独分析。

值域计数的关联练习：

- [[04-题库/Codeforces/1354D-Multiset|1354D Multiset]]

## 自检清单

- [ ] 能画出非二次幂长度数组的区间划分，并正确处理单点和整段查询。
- [ ] 单点修改后会沿祖先路径向上合并，全负数组最值不被 $0$ 污染。
- [ ] 能解释懒标记的状态，完整覆盖与部分覆盖采用不同处理顺序。
- [ ] 能正确处理区间赋值为 $0$、负数加法、加法与赋值的时间顺序。
- [ ] 能推导最大子段和的四字段合并式，区分是否允许空子段。
- [ ] 能说明纯区间加、最后查询时为何可先用差分，以及静态最值何时适合 ST 表。
- [ ] 知道普通懒标记的适用条件，不把所有 `chmin` / `chmax` 问题都当成 Beats。
