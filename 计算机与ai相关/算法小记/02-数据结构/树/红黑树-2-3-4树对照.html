RED–BLACK / 2–3–4

红边合并，黑高数层

把黑结点与它的直接红孩子合并，就是一个 2-3-4 大结点。红孩子在二叉指针上低一层，在逻辑上仍属于同一个大结点。

01 / 一个大结点，怎样拆成二叉树？

MULTIWAY NODE

4-结点：3 个键，4 个外部分支

T₀、T₁……表示原来的孩子子树；若为空，则是外部空分支。

BINARY ENCODING

大小顺序没变，颜色记录组内关系

B：大结点代表R：同组附属键

2 / 3 / 4 说的是分支数，分别存 1 / 2 / 3 个键。普通红黑树的 3-结点可以左红，也可以右红；对应关系不是唯一形状。

02 / 为什么只数黑色？

  • 黑高相等 → 大结点层数相同收缩红边后，每经过一个黑色代表，就进入一个逻辑大结点；2-3-4 树所有叶大结点同层。
  • 不能连续红 → 合法的组内形状红成员直接附属于黑色代表。双红表示编码需要修复，但不一定表示已经装不下。
  • 根黑与 NIL 黑 → 代表与空分支约定根是最上层的独立代表；NIL 没有真实键，作为统一的黑色路径终点。

二叉路径可长可短，但每个逻辑层最多额外经过一个红结点，所以不会退化成任意长的链。

03 / 插入：满了就分，没满就理

父黑
没有双红，直接结束。既可能是 2 → 3，也可能是在另一侧空位插入后 3 → 4。
父红 · 叔红
祖父、父、叔已组成满的 4-结点：父叔变黑，祖父变红向上推。对应分裂，冲突可能继续向上传递。
父红 · 叔黑
三个键仍能放进一个 4-结点，只是编码歪了：把中间键转到上面染黑，两边染红。直线单旋，折线双旋。

不是所有双红都要分裂。50B → 15R → 10R 只有三个键；对 50 右旋并换色后，得到 15B 带 10R、50R，恰好是一个合法 4-结点。

05 / 删除：借与并，修的是逻辑层数

黑兄弟有红孩子
相邻大结点有富余：键经过共同父层交换，旋转与换色完成“借”。近侄先转方向，远侄完成借用。
黑兄弟无红孩子
相邻大结点也只有一个键：从父层取分隔键合并。缺黑可能向上传递；遇红父可吸收，抵达根则结束。
兄弟为红
它和父仍在同一个大结点内，不是真正独立的相邻大结点。先旋转换表示，露出黑兄弟，再讨论借或并。

“双黑”是缺一层黑色的记账方式，不要求代码新增第三种颜色。细节仍需维护实际摘除位置、原颜色及 NIL 的父与左右侧。
