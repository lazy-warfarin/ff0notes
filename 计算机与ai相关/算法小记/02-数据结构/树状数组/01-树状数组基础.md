# 树状数组基础

## 适用场景

- 数组会被修改，还要反复查询前缀和或区间和。
- 统计某个位置之前的元素个数，或把“值的出现次数”当成数组维护。
- 需要一个代码短、空间为 $O(n)$ 的动态前缀统计结构。

树状数组（Fenwick Tree，也叫 Binary Indexed Tree，简称 BIT）最基础的接口是：**单点增加 + 前缀求和**。利用两个前缀和相减，就能查询任意区间和。

选结构时先看操作：静态区间和用前缀和即可；频繁单点修改和区间求和适合树状数组；区间赋值、一般的区间最值等复杂操作通常考虑线段树。区间加法也能通过差分转成树状数组能处理的问题，见 [[02-差分与区间更新|差分与区间更新]]。

## 核心思想

### 1. lowbit：取出最低位的那个 1

对正整数 $x$：

$$
\operatorname{lowbit}(x)=x\mathbin{\&}(-x).
$$

这里的位运算按二进制补码理解。例如：

```text
x = 12 = 1100₂，lowbit(12) = 0100₂ = 4
x = 10 = 1010₂，lowbit(10) = 0010₂ = 2
x =  7 = 0111₂，lowbit(7)  = 0001₂ = 1
```

`x - lowbit(x)` 会清掉最低位的那个 $1$。Rust 的下标通常用 `usize`，不能直接写 `-x`，可以使用 `x & x.wrapping_neg()`。

### 2. 每个结点保存一段区间和

原数组用 $a_1,a_2,\ldots,a_n$ 表示。树状数组中的 `tree[i]` 保存以 $i$ 结尾、长度为 $\operatorname{lowbit}(i)$ 的区间和：

$$
\operatorname{tree}[i]
=\sum_{j=i-\operatorname{lowbit}(i)+1}^{i}a_j.
$$

以 $n=8$ 为例：

```text
tree[1] 管 [1,1]    tree[2] 管 [1,2]
tree[3] 管 [3,3]    tree[4] 管 [1,4]
tree[5] 管 [5,5]    tree[6] 管 [5,6]
tree[7] 管 [7,7]    tree[8] 管 [1,8]
```

它的“树形”关系藏在下标里，不需要真的建立左右孩子结点。

### 3. 查询拆前缀，修改找包含自己的块

- 查询前缀：累加 `tree[i]`，再令 `i -= lowbit(i)`，继续处理左边尚未覆盖的部分。
- 单点修改：更新 `tree[i]`，再令 `i += lowbit(i)`，继续更新包含该位置的更大区间块。

例如查询前 $7$ 个数：$7\to6\to4\to0$，选中 $[7,7]$、$[5,6]$、$[1,4]$，恰好拼成 $[1,7]$，没有重复或遗漏。

修改第 $5$ 个数时：$5\to6\to8$，这三个块都包含位置 $5$。

## 状态定义

- `n`：原数组长度。
- `tree[i]`：区间 $[i-\operatorname{lowbit}(i)+1,i]$ 的和，合法下标为 $1\le i\le n$。
- $S(x)=\sum_{i=1}^{x}a_i$：前缀和，约定 $S(0)=0$。

`tree[i]` 一般不等于 $a_i$，也一般不等于 $S(i)$；它只保存自己负责的那个区间块。

## 转移方程

### 单点增加

把 $a_p$ 增加 $\Delta$，沿着 $i=p,p+\operatorname{lowbit}(p),\ldots$ 更新：

$$
\operatorname{tree}[i]\leftarrow\operatorname{tree}[i]+\Delta.
$$

如果题目要求把 $a_p$ **赋值为** $v$，先计算 $\Delta=v-a_p$。旧值可以另存原数组，也可以通过 `range_sum(p, p)` 查询。

### 区间求和

$$
\operatorname{sum}(l,r)=S(r)-S(l-1),\qquad1\le l\le r\le n.
$$

普通求和允许数组中出现负数；只有后面按前缀和寻找第 $k$ 小时，才需要频率非负带来的单调性。

### 线性建树

先令 `tree[i] = a[i]`，再按下标从小到大，把当前块的完整结果加到父块 $p=i+\operatorname{lowbit}(i)$。每个位置只向父块贡献一次，总时间为 $O(n)$。

## 初始化与边界

- 内部统一使用 **1-based 下标**，分配 `n + 1` 个元素；`tree[0]` 不参与维护。
- `prefix_sum(0)` 合法，返回 $0$；`add(0, delta)` 不合法，因为 `lowbit(0) == 0`，会让更新循环无法前进。
- 对外若使用 0-based 数组，下标先加 $1$ 再调用 `add`。
- 下面的求和类型用 `i64`，调用者须保证累加、相减等中间结果不溢出。
- 长度为 $0$ 时只支持空前缀查询，不存在合法的单点修改或非空区间查询。

## 遍历顺序

查询时下标向左跳，更新时下标向更大的父块跳；线性建树时按下标递增，确保子块已经完整再贡献给父块。

下面是后续笔记共用的 Rust 模板。代码块是知识点示例，不在本仓库建立 Rust 工程。

```rust
struct Fenwick {
    n: usize,
    tree: Vec<i64>,
}

fn lowbit(x: usize) -> usize {
    x & x.wrapping_neg()
}

impl Fenwick {
    fn new(n: usize) -> Self {
        Self { n, tree: vec![0; n + 1] }
    }

    // a 是普通的 0-based 切片；O(n) 建树。
    fn from_slice(a: &[i64]) -> Self {
        let mut bit = Self::new(a.len());
        for i in 1..=bit.n {
            bit.tree[i] += a[i - 1];
            let parent = i + lowbit(i);
            if parent <= bit.n {
                let block_sum = bit.tree[i];
                bit.tree[parent] += block_sum;
            }
        }
        bit
    }

    // a[i] += delta，要求 1 <= i <= n。
    fn add(&mut self, mut i: usize, delta: i64) {
        assert!(1 <= i && i <= self.n);
        while i <= self.n {
            self.tree[i] += delta;
            i += lowbit(i);
        }
    }

    // 返回 a[1..=i] 的和，i == 0 时返回 0。
    fn prefix_sum(&self, mut i: usize) -> i64 {
        assert!(i <= self.n);
        let mut result = 0;
        while i > 0 {
            result += self.tree[i];
            i -= lowbit(i);
        }
        result
    }

    fn range_sum(&self, l: usize, r: usize) -> i64 {
        assert!(1 <= l && l <= r && r <= self.n);
        self.prefix_sum(r) - self.prefix_sum(l - 1)
    }
}
```

手算检查：令 $a=[2,1,3,4,5,2,1,6]$，则 `prefix_sum(7) == 18`、`range_sum(3, 6) == 14`。执行 `add(5, 3)` 后，`range_sum(3, 6) == 17`。

## 空间优化

- 单纯维护单点增量与区间和时，只需要一棵树状数组，空间为 $O(n)$。
- 若要频繁按新值赋值，另存原数组能直接得到旧值；不保存时可用一次单点区间查询换取更少存储。
- 值域很大、实际出现的值很少时，先离散化，见 [[03-离散化逆序对与第k小|离散化、逆序对与第 k 小]]。

## 复杂度

- 单点增加、前缀和、区间和：每次 $O(\log n)$。
- 从零开始逐点加入：$O(n\log n)$；上面的线性建树：$O(n)$。
- 空间：$O(n)$。

查询每次清掉一个二进制 $1$，最多跳 $O(\log n)$ 次；更新也只经过对数个区间块。复杂度按 $n\ge2$ 理解，空数组和单元素情况为常数时间。

## 常见错误

- 更新时从下标 $0$ 开始，造成死循环。
- 把 `add(i, delta)` 当作 `a[i] = delta`。
- 将 `tree[i]` 误当作原数组值，或误当作完整前缀和。
- 把前缀和查询的 `i -= lowbit(i)` 与更新的 `i += lowbit(i)` 写反。
- 把区间和写成 `prefix_sum(r) - prefix_sum(l)`，漏掉左端点。
- 用 32 位整数保存可能达到 $n\max|a_i|$ 的和。
- 直接用两个“前缀最大值”相减求区间最大值。前缀最值树状数组需要专门设计；例如维护前缀最大值且只做单点增大时，可以用 `max` 聚合，但不能照搬区间和的相减公式，也不能直接支持任意减小或赋值。
