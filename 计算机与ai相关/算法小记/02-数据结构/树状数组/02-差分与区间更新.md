# 差分与区间更新

前置：[[01-树状数组基础|树状数组基础]]。本篇的修改统一指“给区间所有元素加上同一个数”，查询区间统一使用闭区间 $[l,r]$。

## 适用场景

- 区间加法修改，随后查询某个位置的值。
- 区间加法修改与区间和查询交替出现。
- 需要把对很多元素的修改，转成对少数边界位置的修改。

如果所有修改完成后才统一查询，普通差分数组加一次前缀累加通常就够了；需要边修改边查询时，再用树状数组维护差分。

## 核心思想

### 1. 区间加法变成两个差分点的修改

令 $a_0=0$，差分数组为：

$$
d_i=a_i-a_{i-1},\qquad a_x=\sum_{i=1}^{x}d_i.
$$

给 $[l,r]$ 加上 $\Delta$，只改变两个边界：

$$
d_l\leftarrow d_l+\Delta,\qquad
d_{r+1}\leftarrow d_{r+1}-\Delta.
$$

当 $r=n$ 时，第二个修改落在数组范围之外，可以直接省略。

所以，一棵维护 $d_i$ 的树状数组即可实现：**两次单点增加完成区间加法，一次前缀和得到原数组的单点值**。

### 2. 区间求和需要再维护一份加权差分

要求原数组前缀和 $P(x)$，展开 $a_i$：

$$
\begin{aligned}
P(x)&=\sum_{i=1}^{x}a_i
=\sum_{i=1}^{x}\sum_{j=1}^{i}d_j\\
&=\sum_{j=1}^{x}(x-j+1)d_j\\
&=x\sum_{j=1}^{x}d_j-\sum_{j=1}^{x}(j-1)d_j.
\end{aligned}
$$

含义很直观：$d_j$ 会出现在 $a_j,a_{j+1},\ldots,a_x$ 中，一共被加 $x-j+1$ 次。

分别维护 $d_j$ 和 $(j-1)d_j$，就能用两棵树状数组还原 $P(x)$。

## 状态定义

- $d_i$：原数组差分。
- `b1`：维护 $d_i$ 的树状数组。
- `b2`：维护 $(i-1)d_i$ 的树状数组。
- $Q_1(x)=\sum_{i=1}^{x}d_i$，$Q_2(x)=\sum_{i=1}^{x}(i-1)d_i$。
- $P(x)=xQ_1(x)-Q_2(x)$，并约定 $P(0)=0$。

一棵差分 BIT 的前缀和是原数组的**单点值**；两棵 BIT 组合后才得到原数组的**前缀和**。先分清维护的对象，再写查询。

## 转移方程

### 区间加、单点查

使用 [[01-树状数组基础|基础模板]]，但让其中的树状数组维护差分：

```text
区间加 [l,r]：
    bit.add(l, delta)
    如果 r < n：bit.add(r + 1, -delta)

查询原数组 a[x]：
    bit.prefix_sum(x)
```

### 区间加、区间查

一次差分点修改 $d_p\leftarrow d_p+\Delta$，对应：

$$
\operatorname{b1.add}(p,\Delta),\qquad
\operatorname{b2.add}(p,(p-1)\Delta).
$$

因此给 $[l,r]$ 加上 $\Delta$ 时，更新量为：

$$
\begin{array}{c|cc}
& p=l & p=r+1\\
\hline
\mathrm{b1} & \Delta & -\Delta\\
\mathrm{b2} & (l-1)\Delta & -r\Delta
\end{array}
$$

当 $r=n$ 时，省略 $r+1$ 处的更新。原数组区间和仍为：

$$
\operatorname{sum}(l,r)=P(r)-P(l-1).
$$

## 初始化与边界

- 原数组全为 $0$ 时，两棵树状数组均初始化为 $0$。
- 原数组非零时，先计算差分，再分别用 $d_i$ 和 $(i-1)d_i$ 建树，不能把原数组直接塞进这两棵 BIT。
- 另一种做法是树中只维护后续增量，初值单独用原数组或静态前缀和处理；使用这种方案时不能再重复把初值加入差分 BIT。
- $r=n$ 时无需访问 `n + 1`；$l=1$ 时查询 `prefix_sum(0)` 返回 $0$。
- 差分允许为负；区间加法的 $\Delta$ 也允许为负。
- 加权差分包含 $(i-1)\Delta$，需要检查**乘法、取负、累加以及最终相减**都能装进 `i64`；只看单个元素的范围不够。

## 遍历顺序

每次区间修改先拆成边界修改，每次查询再组合两棵树的前缀和。操作按题目顺序执行，无需遍历整个区间。

下面代码复用基础篇的 `Fenwick` 定义，两段放在同一模块中使用：

```rust
struct RangeFenwick {
    n: usize,
    b1: Fenwick,
    b2: Fenwick,
}

impl RangeFenwick {
    fn new(n: usize) -> Self {
        Self { n, b1: Fenwick::new(n), b2: Fenwick::new(n) }
    }

    fn from_slice(a: &[i64]) -> Self {
        let n = a.len();
        let mut diff = vec![0; n];
        let mut weighted = vec![0; n];
        for i in 0..n {
            diff[i] = a[i] - if i == 0 { 0 } else { a[i - 1] };
            weighted[i] = diff[i] * i as i64;
        }
        Self {
            n,
            b1: Fenwick::from_slice(&diff),
            b2: Fenwick::from_slice(&weighted),
        }
    }

    fn add_diff(&mut self, p: usize, delta: i64) {
        self.b1.add(p, delta);
        self.b2.add(p, delta * (p as i64 - 1));
    }

    fn range_add(&mut self, l: usize, r: usize, delta: i64) {
        assert!(1 <= l && l <= r && r <= self.n);
        self.add_diff(l, delta);
        if r < self.n {
            self.add_diff(r + 1, -delta);
        }
    }

    fn prefix_sum(&self, x: usize) -> i64 {
        assert!(x <= self.n);
        x as i64 * self.b1.prefix_sum(x) - self.b2.prefix_sum(x)
    }

    fn range_sum(&self, l: usize, r: usize) -> i64 {
        assert!(1 <= l && l <= r && r <= self.n);
        self.prefix_sum(r) - self.prefix_sum(l - 1)
    }
}
```

例：初始 $a=[1,2,3,4,5]$。执行 `range_add(2, 4, 3)` 后，数组变为 $[1,5,6,7,5]$，`range_sum(2, 5) == 23`、`prefix_sum(5) == 24`。

## 空间优化

- 只需区间加、单点查时，维护一棵差分 BIT 即可。
- 需要区间和时，维护两棵 BIT，空间仍为 $O(n)$。
- 示例建树会临时生成两个长度为 $n$ 的数组；建树结束后自动释放。内存紧张时可按定义直接填充两个树数组，再做线性建树。

## 复杂度

- 单次区间加法：$O(\log n)$。
- 单次单点值或区间和查询：$O(\log n)$。
- 按上面差分与线性建树方式初始化：$O(n)$。
- 空间：$O(n)$。

## 常见错误

- 区间加法忘记在 $r+1$ 处撤销增量，导致后面的元素一起被修改。
- 在只分配 `n + 1` 个元素的基础模板里，无条件调用 `add(n + 1, ...)`。
- 混用两套公式：本篇维护 $(i-1)d_i$，对应 $xQ_1-Q_2$；若改成维护 $id_i$，公式应改成 $(x+1)Q_1-Q_2$。
- 将差分 BIT 的 `prefix_sum(x)` 当作原数组的前缀和。
- 原数组非零，却按全零初值建树；或把初值重复计入两次。
- 认为“区间赋值”也能用相同的两个差分点处理。这里的推导依赖可叠加的区间加法。
